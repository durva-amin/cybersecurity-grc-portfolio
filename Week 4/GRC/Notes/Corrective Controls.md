## Definition

**Corrective Controls** are security controls designed to **fix, recover from, or reduce the impact of a security incident after it has occurred or been detected**.

**Simple Definition:**

> Corrective controls help **FIX the problem and restore normal operations**.

---

## What Do Corrective Controls Do?

Corrective controls can help:

- Fix security problems
- Remove malicious software
- Restore lost or damaged data
- Recover affected systems
- Correct security weaknesses
- Reduce the impact of an incident
- Return systems to normal operation

---

## Examples of Corrective Controls

Common examples include:

- Restoring data from backups
- Removing malware
- Applying security patches
- Resetting compromised passwords
- Reconfiguring systems after an incident
- Recovering/rebuilding affected systems
- Updating configurations to fix identified weaknesses
