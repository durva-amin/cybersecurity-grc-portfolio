## Definition

**Technical Controls** are security measures implemented using **technology, hardware, or software** to protect systems, networks, applications, and data.

**Simple Definition:**

> Technical controls use **technology to protect information and systems**.

---

## Examples of Technical Controls

Common examples include:

- Firewalls
- Antivirus / Endpoint protection
- Multi-Factor Authentication (MFA)
- Encryption
- IDS/IPS
- Access control systems
- Password enforcement mechanisms
- Security monitoring tools
- Network segmentation

---

## What Do Technical Controls Do?

Technical controls can help:

- Prevent unauthorized access
- Protect data
- Detect suspicious activities
- Block malicious network traffic
- Verify user identities
- Protect systems from malware
