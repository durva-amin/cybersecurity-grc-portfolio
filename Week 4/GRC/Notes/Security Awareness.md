## Definition

**Security Awareness** is the process of educating employees and users about **security threats, organizational security requirements, and safe practices** so they can protect information and systems.

**Simple Definition:**

> Security Awareness = **Teaching people how to behave securely and recognize security threats.** 👥🛡️

---

# Why Is Security Awareness Important?

Employees interact with:

- Emails
- Passwords
- Company data
- Websites
- Devices
- Applications
- External people/vendors

Attackers often target **people**, not just technology.

Security awareness helps reduce risks caused by:

- Phishing
- Social engineering
- Weak passwords
- Unsafe browsing
- Accidental data disclosure
- Improper handling of sensitive information

---

# What Does Security Awareness Training Cover?

Common topics include:

### 1. Phishing

Employees learn how to recognize suspicious:

- Emails
- Links
- Attachments
- Login pages

### 2. Password Security

Employees learn to:

- Use strong, unique passwords
- Avoid password sharing
- Use approved password managers
- Follow the company's Password Policy

### 3. Social Engineering

Employees learn how attackers may manipulate them into:

- Revealing information
- Sending money
- Sharing credentials
- Providing unauthorized access

### 4. Data Protection

Employees learn how to:

- Handle confidential information
- Share data securely
- Follow data-classification requirements
- Avoid unauthorized disclosure

### 5. Incident Reporting

Employees should know **how and where to report**:

- Suspicious emails
- Lost devices
- Suspected account compromise
- Security incidents

### 6. Physical Security

Training may cover:

- Locking computers
- Protecting access cards
- Preventing tailgating
- Following visitor procedures

---

# Security Awareness Program

Security awareness should not necessarily be just a **one-time training session**.

An organization may use:

- New-employee training
- Periodic refresher training
- Phishing simulations
- Security newsletters/reminders
- Awareness campaigns
- Short quizzes
- Role-specific training

The organization can also track completion and effectiveness.
