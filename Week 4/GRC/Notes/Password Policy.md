**## Definition

A **Password Policy** is a set of rules and requirements defined by an organization for **creating, using, protecting, and managing passwords**.

**Simple Definition:**

> Password Policy = **Rules employees must follow for passwords.**

---

## Why Is a Password Policy Used?

A password policy helps:

- Protect user accounts
- Reduce weak-password risks
- Prevent password sharing
- Reduce password reuse
- Protect sensitive information
- Define secure password-management requirements
- Establish consistent password practices

---

# What Can a Password Policy Include?

### 1. Password Length

Organizations should require sufficiently long passwords or passphrases.

Example:

> Passwords must contain at least **14 characters**.

Longer passwords generally provide better resistance to guessing attacks.

---

### 2. Password Complexity

An organization may define requirements for password construction.

However, modern guidance generally favors **long, unique passwords/passphrases** rather than forcing complicated combinations such as uppercase + lowercase + number + symbol in every password.

Example of a passphrase:

```
Coffee-River-Window-Train-27
```

---

### 3. Unique Passwords

Employees should not reuse the same password across different accounts.

> Work account password ≠ Personal account password

---

### 4. Password Sharing

Passwords should **not be shared** with coworkers or other unauthorized people.

---

### 5. Compromised Passwords

Passwords should be changed when:

- A password is known or suspected to be compromised
- There is evidence of unauthorized access
- A security incident requires credential reset

Modern guidance does **not necessarily require arbitrary periodic password changes** if there is no evidence of compromise.

---

### 6. Default Passwords

Default passwords provided with devices or applications should be **changed before or during deployment**.

Example:

```
admin / admin
```

should not remain in use.

---

### 7. Password Storage

Organizations should not store passwords in **plain text**.

Password verifiers should be protected using appropriate **salted password hashing** mechanisms.

---

### 8. Password Manager

Organizations can use approved password managers to help employees create and store **strong, unique passwords** securely.

---
