## Definition

**Defense in Depth** is a security strategy that uses **multiple layers of security controls** to protect systems, networks, and data.

**Simple Definition:**

> Don't depend on **only one security control**. Use multiple layers of protection.

---

## Why Is Defense in Depth Important?

No security control is perfect.

If one control fails, another control can still provide protection.

It helps:

- Reduce the chance of successful attacks
- Limit the impact of security incidents
- Protect against different types of threats
- Avoid depending on a single security control

---

## How Does It Work?

Think of security as multiple layers:

**Layer 1 → Physical Security**

**Layer 2 → Firewall**

**Layer 3 → MFA**

**Layer 4 → Endpoint Protection**

**Layer 5 → Access Controls**

**Layer 6 → Encryption**

**Layer 7 → Monitoring/Logging**

An attacker may need to overcome several controls instead of just one.
