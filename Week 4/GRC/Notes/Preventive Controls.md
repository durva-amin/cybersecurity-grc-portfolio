## Definition

**Preventive Controls** are security controls designed to **prevent or reduce the chance of a security incident before it happens**.

**Simple Definition:**

> Preventive controls try to **STOP a security problem before it occurs**.

---

## What Do Preventive Controls Do?

Preventive controls help:

- Prevent unauthorized access
- Block malicious activities
- Reduce security risks
- Prevent malware infections
- Protect sensitive information
- Reduce human errors

---

## Examples of Preventive Controls

Common examples include:

- Firewall
- Multi-Factor Authentication (MFA)
- Strong passwords
- Access controls
- Encryption
- Security awareness training
- Door locks
- Network segmentation
- Least privilege

Notice that preventive controls can be **administrative, technical, or physical**.

For example:

|Control|Type|Function|
|---|---|---|
|Security awareness training|Administrative|Preventive|
|Firewall|Technical|Preventive|
|Door lock|Physical|Preventive|

This distinction is important in interviews.
