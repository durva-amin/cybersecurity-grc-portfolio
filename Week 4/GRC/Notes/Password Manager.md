## Definition

A **Password Manager** is a tool used to **securely generate, store, and manage passwords and other credentials**.

**Simple Definition:**

> Password Manager = A **secure vault for your passwords**. 🔐

---

## Why Is a Password Manager Used?

People have many accounts, so remembering a different strong password for every account is difficult.

A password manager helps users:

- Create strong passwords
- Use unique passwords for different accounts
- Store passwords securely
- Reduce password reuse
- Autofill credentials where supported
- Manage many passwords more easily

---

# How Does a Password Manager Work?

Basic process:

**Create/Use Password Manager → Protect Vault → Save Credentials → Vault Protects Stored Data → Retrieve/Autofill When Needed**

Many password managers protect the vault using **encryption**.

The user typically protects access to the vault using a strong **master password** and, where available, **MFA**.

---

## Master Password

A **master password** is the main password used to unlock the password manager.

It should be:

- Long
- Unique
- Difficult to guess
- Not reused for another account

> If the master password protects all your stored credentials, protecting it is extremely important.

---

## Password Generator

Password managers commonly include a **password generator**.

For example, instead of creating:

```
durva123
```

the manager could generate a long random password such as:

```
g7!Qx2#L9v@R4mZ8
```

The user doesn't have to memorize every generated password because the password manager stores them.
