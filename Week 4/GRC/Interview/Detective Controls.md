# Interview Questions

### Q1. What is a Detective Control?

**Answer:**  
A detective control is a security measure designed to identify security incidents, suspicious activities, errors, or violations.

### Q2. Give examples of Detective Controls.

**Answer:**  
IDS, log monitoring, SIEM alerts, security audits, CCTV monitoring, and file integrity monitoring.

### Q3. Is IDS a Detective Control?

**Answer:**  
Yes. An **Intrusion Detection System** detects suspicious network activity and generates alerts.

### Q4. What is the difference between Detective and Preventive Controls?

**Answer:**  
Preventive controls try to **stop an incident from occurring**, while detective controls help **identify an incident or suspicious activity**.

### Q5. Is log monitoring a Detective Control?

**Answer:**  
Yes. Log monitoring can identify suspicious activities and security events.

### Q6. Why are Detective Controls important?

**Answer:**  
Because preventive controls cannot stop every threat. Detective controls help organizations discover incidents quickly so they can investigate and respond.

# Scenario-Based Question

### Q. A company's monitoring system detects 100 failed login attempts from the same source and sends an alert to the security team. What type of control is this?

**Answer:**  
It is a **Detective Control** because the system **detected suspicious activity and generated an alert**.
