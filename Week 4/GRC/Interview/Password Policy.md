# Interview Questions

### Q1. What is a Password Policy?

**Answer:**  
A Password Policy is a set of organizational rules for securely creating, using, protecting, and managing passwords.

### Q2. Why is a Password Policy important?

**Answer:**  
It reduces risks from weak, reused, shared, or compromised passwords and helps protect organizational accounts and information.

### Q3. Should employees share passwords?

**Answer:**  
No. Passwords should not be shared with unauthorized individuals.

### Q4. Should passwords be changed every 30 or 90 days?

**Answer:**  
Not necessarily. Modern guidance generally recommends changing passwords when there is evidence or suspicion of compromise rather than forcing arbitrary periodic changes, unless another applicable requirement requires rotation.

### Q5. Should passwords be stored in plain text?

**Answer:**  
No. Passwords should not be stored in plain text. Systems should use appropriate secure password-hashing mechanisms.

### Q6. Why should passwords be unique?

**Answer:**  
If the same password is reused and one account is compromised, attackers may try the stolen password on other accounts.

### Q7. What makes a strong password?

**Answer:**  
A strong password should be **long, unique, difficult to guess, and not based on commonly used or compromised passwords**.

### Q8. What should happen if a password is compromised?

**Answer:**  
The password should be changed promptly, the affected account should be investigated, and additional security actions should be taken where necessary.

# Scenario-Based Question

### Q. During an audit, you discover employees are using the same password for personal and company accounts. What would you recommend?

**Answer:**  
I would recommend enforcing the organization's Password Policy requiring **unique passwords**, educating employees about password reuse risks, encouraging an approved password manager, and using MFA where appropriate.
