 # Interview Questions

### Q1. What is a Password Manager?

**Answer:**  
A password manager is a tool used to securely generate, store, and manage passwords and credentials.

### Q2. Why should organizations use Password Managers?

**Answer:**  
They make it easier for users to maintain strong, unique passwords and reduce password reuse.

### Q3. What is a Master Password?

**Answer:**  
It is the primary password used to unlock the password manager's vault.

### Q4. Should the Master Password be reused?

**Answer:**  
No. It should be strong and unique and should not be reused for other accounts.

### Q5. How does a Password Manager improve security?

**Answer:**  
It helps users generate and securely store unique passwords, reducing weak-password and password-reuse risks.

### Q6. What happens if the Password Manager is compromised?

**Answer:**  
It can create significant risk because many credentials may be stored there. Organizations should therefore use trusted password managers, strong vault protection, MFA where supported, secure configuration, and appropriate monitoring.

### Q7. Does using a Password Manager mean users don't need MFA?

**Answer:**  
No. Password managers and MFA solve different problems. MFA provides an additional authentication layer and should still be used where appropriate.

# Scenario-Based Question

### Q. During an audit, you discover an employee keeps passwords for 20 company accounts in a plain-text Excel file. What would you recommend?

**Answer:**  
I would recommend stopping the insecure storage practice and using an **organization-approved password manager** to securely store and manage credentials.

The employee should also use **unique passwords** and MFA where required.
