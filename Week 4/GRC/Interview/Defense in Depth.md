# Interview Questions

### Q1. What is Defense in Depth?

**Answer:**  
Defense in Depth is a security strategy that uses multiple layers of security controls to protect systems, networks, and data.

### Q2. Why is Defense in Depth important?

**Answer:**  
Because no single security control is perfect. If one control fails, other controls can continue protecting the organization.

### Q3. Give an example of Defense in Depth.

**Answer:**  
Using a firewall, MFA, endpoint protection, encryption, access controls, physical security, and monitoring together.

### Q4. Is using only a firewall Defense in Depth?

**Answer:**  
No. Defense in Depth requires **multiple complementary layers of security**, not reliance on a single control.

### Q5. Does Defense in Depth include only Technical Controls?

**Answer:**  
No. It can combine:

- Administrative controls
- Technical controls
- Physical controls

### Q6. What is the main goal of Defense in Depth?

**Answer:**  
The goal is to make attacks harder and reduce the impact if one security control fails.

### Q7. Is Defense in Depth the same as having many security tools?

**Answer:**  
Not necessarily. The controls should provide **meaningful layers of protection** against risks. Simply installing many unrelated tools does not automatically create effective Defense in Depth.

# Scenario-Based Question

### Q. A company already has a firewall. Management asks why it also needs MFA, antivirus, encryption, and monitoring. How would you explain it?

**Answer:**  
I would explain that relying only on a firewall creates a single layer of protection.

Using MFA, endpoint protection, encryption, monitoring, and other controls creates **Defense in Depth**.

If one control fails or is bypassed, other controls can still help prevent, detect, or limit the attack.
