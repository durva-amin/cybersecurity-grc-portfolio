# Quick Revision

- **Preventive = STOP before it happens**
- Examples:
    - Firewall
    - MFA
    - Strong passwords
    - Access controls
    - Door locks
    - Least privilege
    - Security awareness training

### ⭐ Easy Trick

> **Preventive → STOP 🛑**  
> **Detective → FIND 🔍**  
> **Corrective → FIX 🔧**

And remember:

> **Administrative / Technical / Physical = HOW the control is implemented**

> **Preventive / Detective / Corrective = WHAT the control does**
