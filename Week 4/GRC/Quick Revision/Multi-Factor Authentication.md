# Quick Revision

- **MFA = 2 or more different authentication factors**
- Main factors:
    - **Know** → Password/PIN
    - **Have** → Phone/security key
    - **Are** → Fingerprint/face
- Protects against stolen-password risk
- **2FA is a type of MFA**
- Password + PIN ≠ true MFA because both are the same factor type.

### ⭐ Easy Trick

Remember **K-H-A**:

> 🧠 **K → Know** → Password  
> 📱 **H → Have** → Phone/key  
> 👆 **A → Are** → Fingerprint

**MFA = More than one type of proof 🔐**
