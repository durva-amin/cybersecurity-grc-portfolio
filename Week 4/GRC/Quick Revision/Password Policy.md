# Quick Revision

- **Password Policy = Password rules**
- Use **long passwords/passphrases**
- Use **unique passwords**
- Don't share passwords
- Don't keep default passwords
- Don't store passwords in plain text
- Change compromised passwords
- Use an approved password manager
- Use MFA where appropriate

### ⭐ Easy Trick

Remember **L-U-S-C**:

> **L → Long**  
> **U → Unique**  
> **S → Secret**  
> **C → Change if Compromised**

**Password Policy = Rules for safer password management 🔐**
