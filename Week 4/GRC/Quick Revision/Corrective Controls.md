# Quick Revision

- **Corrective = FIX / RECOVER**
- Used after a problem is **identified**
- Examples:
    - Restore from backup
    - Remove malware
    - Reset compromised passwords
    - Apply fixes/patches
    - Rebuild affected systems

### ⭐ Easy Trick

> **Preventive → STOP 🛑**  
> **Detective → FIND 🔍**  
> **Corrective → FIX 🔧**

### Simple Example

**Firewall blocks attack → Preventive**

**SIEM alerts about attack → Detective**

**Restore affected system → Corrective**
