# Quick Revision

- **Security Awareness = Educate employees about security**
- Covers:
    - Phishing
    - Passwords
    - Social engineering
    - Data protection
    - Incident reporting
    - Physical security
- Generally an **Administrative Control**
- Can perform a **Preventive function**
- Should be **ongoing**, not just one-time training.
- Effectiveness should be measured.

### ⭐ Easy Trick

> **Technology protects systems 💻**  
> **Security Awareness strengthens the human layer 👥**

**Know the threat → Recognize it → Avoid it → Report it 🛡️**
