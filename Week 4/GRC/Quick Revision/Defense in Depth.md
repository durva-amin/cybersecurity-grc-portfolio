# Quick Revision

- **Defense in Depth = Multiple security layers**
- Never depend on only one control.
- If **Layer 1 fails → Layer 2 protects**
- Can include:
    - Physical security
    - Firewall
    - MFA
    - Endpoint protection
    - Access control
    - Encryption
    - Monitoring

### ⭐ Easy Trick

Think of a **castle 🏰**:

> **Wall → Gate → Guards → Locked door → Safe**

An attacker must cross **multiple layers**.

**Defense in Depth = Layer upon Layer of Security 🛡️🛡️🛡️**
