# Quick Revision

- **Detective Control = Detect problems**
- Detects:
    - Attacks
    - Suspicious activity
    - Unauthorized access
    - Errors
    - Policy violations
- Examples:
    - IDS
    - SIEM alerts
    - Log monitoring
    - CCTV monitoring
    - Security audits
- Does not necessarily stop the attack itself.

### ⭐ Easy Trick

Remember the security sequence:

> **Preventive → STOP 🛑**  
> **Detective → FIND 🔍**  
> **Corrective → FIX 🔧**

**Detective = Detective investigates and finds clues 🔍**
