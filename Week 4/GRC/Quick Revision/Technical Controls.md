# Quick Revision

- **Technical Controls = Technology-based security**
- Protect **systems, networks, applications, and data**
- Examples:
    - Firewall
    - Antivirus
    - MFA
    - Encryption
    - IDS/IPS
    - Access controls

### ⭐ Easy Trick

Remember:

> **Administrative → Rules 📋**  
> **Technical → Technology 💻**  
> **Physical → Physical protection 🔐**

**If software or hardware is directly implementing the security protection → think Technical Control.**
