# Quick Revision

- **Encryption = Plaintext → Ciphertext**
- **Decryption = Ciphertext → Plaintext**
- Uses cryptographic **algorithms + keys**
- Protects **Confidentiality**
- **Data at Rest** → Stored data
- **Data in Transit** → Moving data
- Encryption is **reversible with the appropriate key**

### ⭐ Easy Trick

> 📄 **Plaintext** = You can read it  
> 🔐 **Encryption** = Lock it  
> 🔣 **Ciphertext** = Can't understand it  
> 🔑 **Decryption** = Unlock it

**Encryption = Lock your data with cryptography 🔐**
