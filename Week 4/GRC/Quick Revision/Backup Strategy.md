# Quick Revision

- **Backup Strategy = Backup + Protect + Test + Restore**
- Types:
    - **Full → Everything**
    - **Incremental → Since latest backup**
    - **Differential → Since last full**
- **3-2-1 Rule → 3 copies, 2 media/storage types, 1 off-site**
- **RPO → Acceptable data loss**
- **RTO → Target recovery time**
- Test backups regularly.

### ⭐ Easy Trick

> **Backup = Have a copy 💾**  
> **Recovery = Get it back 🔄**

And:

> **RPO → How much DATA can we lose?**  
> **RTO → How much TIME can we take?**
