# Quick Revision

- **Password Manager = Secure password vault**
- Helps:
    - Generate passwords
    - Store passwords
    - Manage passwords
    - Reduce password reuse
- Protect the vault with:
    - Strong master password
    - MFA where available
- Never use the master password elsewhere.

### ⭐ Easy Trick

> **Password Policy = Makes the rules 📋**  
> **Password Manager = Helps manage the passwords 🔐**

**One strong master password → Secure vault → Many unique passwords**
