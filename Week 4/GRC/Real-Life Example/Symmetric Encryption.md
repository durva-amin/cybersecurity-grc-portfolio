# Real-Life Example

Suppose a company encrypts a large database using **AES**.

A secret encryption key is used to encrypt the database.

The appropriate secret key is required to decrypt the information.

This is **Symmetric Encryption**.

---

# Symmetric vs Asymmetric — Basic Difference

You'll study asymmetric encryption separately, but remember:

|Symmetric|Asymmetric|
|---|---|
|Same secret key|Public + Private key pair|
|Generally faster|Generally slower|
|Good for bulk data encryption|Useful for key exchange, signatures, etc.|
|AES|RSA/ECC-based systems|
