 ## Real-Life Example

A company has two employees:

**Employee A – Accountant**

- View financial records ✅
- Update financial records if required ✅
- Change firewall configuration ❌

**Employee B – Network Administrator**

- Manage network devices ✅
- Configure firewall if required ✅
- Access employee salary information ❌

Each person receives only the permissions required for their job.

This follows **Least Privilege**.

---

## Least Privilege Applies to More Than Users

Least privilege can apply to:

- User accounts
- Administrator accounts
- Applications
- Services
- Processes
- Database accounts

For example, an application that only needs to **read** data should not automatically receive permission to **delete** it.
