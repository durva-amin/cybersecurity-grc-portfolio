## Real-Life Example

An employee has:

- Company email
- HR portal
- Cloud account
- Project-management account

❌ Instead of using:

```
SamePassword123
```

for every account, the employee uses a password manager to generate and store a **different strong password for each account**.

This reduces password-reuse risk.

---

## Password Manager vs Password Policy

|Password Policy|Password Manager|
|---|---|
|Defines password rules|Helps users manage passwords|
|Administrative control|Primarily a technical tool|
|Says what users should follow|Helps users follow secure practices|

Example:

> **Policy:** Use unique passwords.  
> **Password Manager:** Helps generate and store those unique passwords.
