### Interview Questions

**Q1. What is a corrective control?**  
**Answer:** A corrective control is designed to address a security incident or weakness and help restore the system to a secure state.

**Q2. Give an example of a corrective control.**  
**Answer:** Restoring a compromised system from a known-good backup is an example of a corrective control.

**Q3. What is the difference between preventive, detective, and corrective controls?**  
**Answer:**

- **Preventive:** Tries to stop the incident.
- **Detective:** Identifies the incident.
- **Corrective:** Takes action to address the incident and restore security.

### Scenario-Based Question

**Q. A security team detects malware on an employee's computer and removes the malware before restoring the system to a clean state. What type of control is involved?**

**Answer:** This is a **corrective control** because action is being taken to address the security incident and restore the system.
