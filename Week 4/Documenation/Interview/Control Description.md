### Interview Questions

**Q1. What is a control description?**  
**Answer:** It explains what a security control does and how it operates.

**Q2. What is the difference between a control objective and control description?**  
**Answer:** The **objective** explains what the control should achieve, while the **description** explains what the control does and how it operates.

**Q3. Why should a control description be clear?**  
**Answer:** So that employees, auditors, and other stakeholders can understand how the control is implemented and operates.

### Scenario-Based Question

**Q. An organization has a password policy requiring minimum password length and complexity. What would you write as the control description?**

**Answer:**

> The organization enforces password requirements for user accounts, including minimum password length and complexity requirements.
