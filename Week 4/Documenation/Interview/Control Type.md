### Interview Questions

**Q1. What is a control type?**  
**Answer:** It is the classification assigned to a security control based on its nature, purpose, or function.

**Q2. Why is control classification important?**  
**Answer:** It helps organizations understand how different controls manage security risks and organize their control environment.

**Q3. Can one security control have more than one classification?**  
**Answer:** Yes. A control can be classified from different perspectives. For example, MFA can be both **technical** and **preventive**.

### Scenario-Based Question

**Q. An organization uses a firewall to block unauthorized network traffic. How could the firewall be classified?**

**Answer:** It can be classified as a **technical control** and a **preventive control**.
