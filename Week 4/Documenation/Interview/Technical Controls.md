### Interview Questions

**Q1. What is a technical control?**  
**Answer:** A technical control is a security mechanism implemented through technology to protect systems, networks, applications, or information.

**Q2. Give an example of a technical control.**  
**Answer:** A firewall is a technical control because it uses technology to control and filter network traffic.

**Q3. What is the difference between administrative and technical controls?**  
**Answer:** Administrative controls focus on **policies, procedures, and processes**, while technical controls use **technology and systems** to implement security measures.

### Scenario-Based Question

**Q. An organization uses encryption to protect sensitive customer information. What type of control is encryption?**

**Answer:** Encryption is a **technical control** because it uses technology to protect information.
