### Interview Tip ⭐

Remember:

**Preventive = Stop it**  
**Detective = Find it**  
**Corrective = Fix it**

### Quick Revision

- Corrective controls address **identified security issues or incidents**.
- They help **restore or improve the security state**.
- Examples: **system restoration, malware removal, credential reset, security patching**.
- Think: **"How do we fix it?"**
