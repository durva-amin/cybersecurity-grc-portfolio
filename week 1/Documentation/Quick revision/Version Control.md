- Version Control tracks document changes.
- Maintains document history.
- Ensures the latest version is used.
- **1.0** = First official release.
- **1.1** = Minor update.
- **2.0** = Major update.

### 🔑 Easy Trick to Remember

**1.0 → New** 🆕

**1.1 → Small Change** ✏️

**2.0 → Big Change** 🚀

**Memory Rule:**

> **Small change = Decimal changes (1.1, 1.2)**  
> **Big change = Whole number changes (2.0, 3.0)**
