## Definition

**Version Control** is the process of tracking and managing changes made to a document over time.

### Simple Definition

Version Control means **keeping track of every update made to a document**.

---

## Why is Version Control Important?

- Tracks document changes.
- Prevents confusion between old and new versions.
- Ensures employees use the latest approved document.
- Supports audits and compliance.
- Maintains document history.

---

## Common Version Numbers

### Version 1.0

First official release of the document.

### Version 1.1

Minor changes or corrections.

### Version 1.2

Additional minor updates.

### Version 2.0

Major changes or complete revision.
