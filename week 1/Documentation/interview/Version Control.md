## Interview Questions

### Q1. What is Version Control?

**Answer:**  
Version Control is the process of tracking and managing changes made to a document over time.

### Q2. Why is Version Control important?

**Answer:**  
It helps track changes, ensures employees use the latest document, and supports audits.

### Q3. What does Version 1.0 mean?

**Answer:**  
It is the first official release of a document.

### Q4. What is the difference between Version 1.1 and 2.0?

**Answer:**

- **Version 1.1:** Minor changes or corrections.
- **Version 2.0:** Major changes or significant updates.

---

## Scenario-Based Question

**Q.** During an audit, employees are using both **Password Policy Version 1.0** and **Version 2.0**. What is the issue?

**Answer:**  
Poor version control. Employees should use only the latest approved version to ensure consistency and compliance.



A common interview question is:

**"Why is Version Control important in GRC?"**

**Answer:**  
Version Control ensures that only the latest approved document is used, maintains a history of changes, and provides evidence during audits.
