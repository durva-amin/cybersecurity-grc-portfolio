## Interview Questions

### Q1. What is Information Security Documentation?

**Answer:**  
Information Security Documentation is a collection of written documents that define an organization's security policies, procedures, and responsibilities.

### Q2. Why is Information Security Documentation important?

**Answer:**  
It ensures consistency, supports compliance, manages risks, and provides evidence during audits.

### Q3. Name three Information Security documents.

**Answer:**

- Information Security Policy
- Incident Response Procedure
- Risk Assessment Report

### Q4. Who uses Information Security Documentation?

**Answer:**  
Employees, IT teams, GRC professionals, auditors, and management.

## Scenario-Based Question

**Q.** During an audit, the auditor asks for the organization's Password Policy, but no written document exists. What could happen?

**Answer:**  
The organization may fail the audit because it cannot provide documented evidence of its security requirements.



**Security Controls vs Documentation**

**Security Controls:** Measures that protect systems (e.g., firewall, MFA, antivirus).

**Documentation:** Written documents that explain **what** controls must be implemented and **how** they should be managed.
