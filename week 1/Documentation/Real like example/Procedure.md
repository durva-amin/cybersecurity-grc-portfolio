A company's **Password Policy** says:

> "All employees must enable Multi-Factor Authentication (MFA)."

The **MFA Setup Procedure** explains:

1. Log in to the company portal.
2. Open Security Settings.
3. Select Enable MFA.
4. Scan the QR code using an authenticator app.
5. Verify the code.
6. Save the changes.

This is a **Procedure** because it explains **how** to complete the task.
