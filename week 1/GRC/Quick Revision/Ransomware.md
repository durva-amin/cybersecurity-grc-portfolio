- **Ransomware = Encrypts files and demands money.**
- Main goal is **financial gain**.
- Common spread methods: phishing emails, malicious downloads, and unpatched software.
- Preventive measures include regular backups, software updates, and user awareness.




**Virus vs Trojan vs Ransomware**

- **Virus:** Infects files and spreads when the infected file is opened.
- **Trojan:** Pretends to be legitimate software to trick users.
- **Ransomware:** Encrypts files or locks the system and demands a ransom.

**Easy Trick to Remember:**

- **Virus** → Infects
- **Trojan** → Tricks
- **Ransomware** → Locks and demands money
