- **Trojan = Fake software that appears legitimate.**
- Tricks users into installing it.
- Does **not** spread automatically.
- Can steal data and give attackers unauthorized access.



### Virus vs Worm vs Trojan

|Virus|Worm|Trojan|
|---|---|---|
|Needs a host file|No host file|Looks like genuine software|
|Needs user action|Spreads automatically|User installs it|
|Infects files|Infects networks|Tricks users|

**Easy Trick to Remember:**

- **Virus** → Attaches to a file.
- **Worm** → Spreads by itself.
- **Trojan** → Pretends to be a genuine program.
