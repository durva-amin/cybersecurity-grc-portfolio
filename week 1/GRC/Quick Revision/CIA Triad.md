| Principle       | Meaning                               | Example           |
| --------------- | ------------------------------------- | ----------------- |
| Confidentiality | Only authorized users can access data | HR salary records |
| Integrity       | Data remains accurate and unchanged   | Student marks     |
| Availability    | Data is available when needed         | Online banking    |


**Q  Which principle of the CIA Triad is affected in each case?"**

- Data is leaked → **Confidentiality**
- Data is changed → **Integrity**
- System is down or unavailable → **Availability**
