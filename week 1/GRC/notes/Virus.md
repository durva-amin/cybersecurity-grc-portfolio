## Definition

A **Virus** is a type of **malware** that **attaches itself to a file or program** and spreads when the infected file is opened or executed.

**Simple Definition:**

> A virus is a harmful program that **needs a host file or program to spread.**

---

## Characteristics of a Virus

- Attaches to a file or program.
- Requires user action (e.g., opening a file) to spread.
- Can damage, modify, or delete files.
- Can slow down or crash a system.

---

## How Does a Virus Spread?

- Infected email attachments
- Downloading infected software
- USB drives
- Sharing infected files
