## Definition

**Authorization** is the process of **deciding what an authenticated user is allowed to access or do**.

**Simple Definition:**

> Authorization answers the question: **"What are you allowed to do?"**

---

## Why is Authorization Important?

- Prevents unauthorized access to resources.
- Ensures users only access data they are permitted to.
- Protects sensitive information.

---

## How Authorization Works

Authorization happens **after authentication**.

Example:

1. User logs in with a password. (**Authentication**)
2. The system checks what files or features the user can access. (**Authorization**)

---

## Types of Access

A user may be allowed to:

- Read
- Write
- Edit
- Delete
- Execute
