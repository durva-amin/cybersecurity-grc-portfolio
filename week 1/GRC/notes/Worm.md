## Definition

A **Worm** is a type of **malware** that **spreads automatically from one computer to another without needing a host file or user action.**

**Simple Definition:**

> A worm is harmful software that **spreads by itself over a network.**

---

## Characteristics of a Worm

- Does **not** need a host file.
- Spreads automatically.
- Can infect many computers quickly.
- Uses network vulnerabilities to spread.

---

## How Does a Worm Spread?

- Computer networks
- Internet
- Unpatched systems
- Network vulnerabilities
