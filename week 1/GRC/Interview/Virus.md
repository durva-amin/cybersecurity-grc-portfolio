# Interview Questions

### Q1. What is a Virus?

**Answer:**  
A virus is a type of malware that attaches itself to a file or program and spreads when the infected file is opened or executed.

---

### Q2. Does a Virus need a host file?

**Answer:**  
Yes. A virus needs a host file or program to spread.

---

### Q3. How does a Virus spread?

**Answer:**  
Through infected files, email attachments, software downloads, and USB drives.

---

### Q4. What damage can a Virus cause?

**Answer:**  
It can corrupt files, delete data, slow down the system, or cause the computer to crash.

---

# Scenario-Based Question

### Q. An employee opens an infected email attachment, and the virus starts infecting other files on the computer. What type of malware is this?

**Answer:**  
**Virus**, because it spreads after the infected file is opened.


**"What is the difference between a Virus and a Worm?"**

**Answer:**

- **Virus:** Needs a host file and user action to spread.
- **Worm:** Does **not** need a host file or user action. It spreads automatically through networks.
