# Interview Questions

### Q1. What is a Trojan?

**Answer:**  
A Trojan is a type of malware that disguises itself as legitimate software to trick users into installing it.

---

### Q2. Does a Trojan spread automatically?

**Answer:**  
No. A Trojan relies on users to download or install it.

---

### Q3. How does a Trojan enter a system?

**Answer:**  
Through fake software, email attachments, malicious websites, or cracked software.

---

### Q4. What damage can a Trojan cause?

**Answer:**  
It can steal data, install other malware, provide remote access to attackers, and modify or delete files.

---

# Scenario-Based Question

### Q. A user downloads a free game from an untrusted website. The game works, but it secretly installs malicious software. What type of malware is this?

**Answer:**  
**Trojan**, because it disguises itself as legitimate software.
