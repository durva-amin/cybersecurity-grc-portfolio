# Interview Questions

### Q1. What is a Worm?

**Answer:**  
A worm is a type of malware that spreads automatically across computers and networks without requiring a host file or user action.

---

### Q2. Does a Worm need a host file?

**Answer:**  
No. A worm is a standalone program and does not need a host file.

---

### Q3. How does a Worm spread?

**Answer:**  
It spreads automatically through networks by exploiting vulnerabilities.

---

### Q4. What damage can a Worm cause?

**Answer:**  
It can spread rapidly, consume network resources, slow down systems, and infect multiple computers.

---

# Scenario-Based Question

### Q. One computer in a company gets infected, and within minutes all computers on the network are infected without anyone opening any files. What type of malware is this?

**Answer:**  
**Worm**, because it spreads automatically across the network.
