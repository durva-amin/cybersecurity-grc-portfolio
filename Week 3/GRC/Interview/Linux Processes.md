# Interview Questions

### Q1. What is a Linux process?

**Answer:**  
A Linux process is a running instance of a program.

### Q2. What is a PID?

**Answer:**  
PID stands for **Process ID**. It is a unique number used to identify a process.

### Q3. What is the difference between a program and a process?

**Answer:**  
A **program** is a set of instructions stored on disk, while a **process** is that program while it is running.

### Q4. What is a parent process?

**Answer:**  
A parent process is a process that creates another process, called a child process.

### Q5. Why are processes important in cybersecurity?

**Answer:**  
Monitoring processes can help identify suspicious programs, unusual activity, and potentially malicious processes.

### Q6. Which commands can be used to view Linux processes?

**Answer:**  
Common commands include **`ps` and `top`**.

# Scenario-Based Question

### Q. A security analyst suspects that a malicious program is running on a Linux server. What should they check?

**Answer:**  
They can examine the **running processes** using commands such as `ps` or `top` and investigate suspicious processes further.
