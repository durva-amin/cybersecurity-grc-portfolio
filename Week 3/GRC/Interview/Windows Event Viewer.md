# Interview Questions

### Q1. What is Windows Event Viewer?

**Answer:**  
Windows Event Viewer is a built-in tool used to view and analyze logs and events generated by Windows, applications, and other system components.

### Q2. Why is Event Viewer useful for cybersecurity?

**Answer:**  
It can help analysts investigate security events, authentication failures, system problems, and other suspicious activity recorded in logs.

### Q3. What are the main Windows logs?

**Answer:**  
The main logs include **Application, Security, System, Setup, and Forwarded Events**.

### Q4. Where would you look for login-related security events?

**Answer:**  
The **Security** log, provided that the relevant auditing is enabled.

### Q5. What is the difference between an Error and a Warning?

**Answer:**  
A **Warning** indicates a condition that may require attention, while an **Error** indicates that a problem occurred.

### Q6. Can Event Viewer prevent an attack?

**Answer:**  
No. Event Viewer is primarily a **logging and analysis tool**. It helps you investigate what happened rather than directly preventing attacks.

# Scenario-Based Question

### Q. A security analyst notices many failed login attempts on a Windows computer and wants to investigate them. Which Windows tool can they check?

**Answer:**  
**Windows Event Viewer**, particularly the **Security log**, to investigate recorded authentication-related events.
