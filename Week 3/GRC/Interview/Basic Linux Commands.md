# Interview Questions

### Q1. What is the purpose of `pwd`?

**Answer:**  
It shows the **current working directory**.

### Q2. What is the difference between `cp` and `mv`?

**Answer:**  
`cp` **copies** a file or directory, while `mv` **moves or renames** it.

### Q3. What does `rm` do?

**Answer:**  
It removes files or, with appropriate options, directories.

### Q4. Which command shows the current user?

**Answer:**

whoami

### Q5. Which command is used to search for text?

**Answer:**

grep

### Q6. Which command is used to find files?

**Answer:**

find

### Q7. Which command shows running processes?

**Answer:**

ps

or:

top

### Q8. Which command changes file permissions?

**Answer:**

chmod

### Q9. Which command changes file ownership?

**Answer:**

chown

### Q10. What is `sudo` used for?

**Answer:**  
It allows an authorized user to run a command with **elevated privileges**.

# Scenario-Based Question

### Q. You are working on a Linux server and need to find a file named `report.txt` inside `/home`. Which command could you use?

**Answer:**

find /home -name "report.txt"
