# Interview Questions

### Q1. What is Linux?

**Answer:**  
Linux is an open-source operating system kernel used as the foundation of many Linux distributions.

### Q2. Is Linux an operating system?

**Answer:**  
Strictly speaking, **Linux is the kernel**. Complete systems such as Ubuntu are Linux distributions that use the Linux kernel along with other software.

### Q3. What is a Linux distribution?

**Answer:**  
A Linux distribution is a complete operating system built around the Linux kernel, such as Ubuntu, Debian, or Fedora.

### Q4. Give some examples of Linux distributions.

**Answer:**  
**Ubuntu, Debian, Fedora, Kali Linux, and RHEL** are examples.

### Q5. Why is Linux important in cybersecurity?

**Answer:**  
Linux is widely used in servers, cloud environments, security tools, and network infrastructure, so cybersecurity professionals often need Linux knowledge.

### Q6. What is the Linux terminal?

**Answer:**  
The terminal is a command-line interface through which users can interact with the Linux system by executing commands.

# Scenario-Based Question

### Q. A company runs several web servers on Linux. A security analyst needs to investigate processes and system logs on one of those servers. Why would Linux knowledge be useful?

**Answer:**  
Linux knowledge allows the analyst to use the terminal and understand **processes, permissions, files, and logs**, which are important for investigating and securing the server.
