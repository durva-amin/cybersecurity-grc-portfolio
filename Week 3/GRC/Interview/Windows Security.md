# Interview Questions

### Q1. What is Windows Security?

**Answer:**  
Windows Security is a built-in Windows security interface that provides several tools to protect a computer from malware, network threats, unsafe applications, and unauthorized access.

### Q2. What are some features of Windows Security?

**Answer:**  
Some important features include **Virus & threat protection, Firewall & network protection, App & browser control, Device security, and Account protection**.

### Q3. Is Windows Security an antivirus?

**Answer:**  
Windows Security is **not just an antivirus**. It is a security interface that brings together multiple Windows security features, including Microsoft's built-in antivirus protection.

### Q4. Why is Windows Security important?

**Answer:**  
It helps protect the system against malware, unsafe applications, network threats, and other security risks.

### Q5. Where can you access Windows Security?

**Answer:**  
In Windows, you can search for **Windows Security** from the Start menu and open the application.

# Scenario-Based Question

### Q. An employee downloads a suspicious file from the Internet. Which built-in Windows security interface can they use to check the system's protection status and virus protection?

**Answer:**  
**Windows Security**, particularly the **Virus & threat protection** section.
