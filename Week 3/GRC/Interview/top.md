# Interview Questions

### Q1. What is `top`?

**Answer:**  
`top` is a Linux command used to monitor running processes and system resource usage in real time.

### Q2. What information does `top` show?

**Answer:**  
It can show processes, PIDs, CPU usage, memory usage, process owners, and system load.

### Q3. What is the difference between `ps` and `top`?

**Answer:**  
`ps` provides a **snapshot** of processes, while `top` continuously updates the process and resource information in real time.

### Q4. How do you exit `top`?

**Answer:**  
Press:

q

### Q5. How can `top` help in cybersecurity?

**Answer:**  
It can help identify unusual processes or abnormal CPU and memory usage that may require further investigation.
