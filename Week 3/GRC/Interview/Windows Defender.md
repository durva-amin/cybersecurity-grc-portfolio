# Interview Questions

### Q1. What is Windows Defender?

**Answer:**  
Windows Defender, now called **Microsoft Defender Antivirus**, is Microsoft's built-in antivirus and antimalware protection for Windows.

### Q2. What does Windows Defender protect against?

**Answer:**  
It helps protect against malware such as viruses, worms, Trojans, spyware, and ransomware.

### Q3. What is Real-Time Protection?

**Answer:**  
Real-Time Protection continuously monitors the system for suspicious or malicious activity and can take action when a threat is detected.

### Q4. What is the difference between Quick Scan and Full Scan?

**Answer:**  
A **Quick Scan** checks common locations where threats are likely to be found, while a **Full Scan** checks the entire system.

### Q5. Is Windows Defender the same as Windows Security?

**Answer:**  
No.

- **Microsoft Defender Antivirus** → Antivirus/antimalware protection.
- **Windows Security** → The Windows security interface that provides access to Defender and other security features.

# Scenario-Based Question

### Q. An employee downloads a suspicious executable file. Windows detects it as malicious and moves it to an isolated location so it cannot run normally. Which security feature is responsible?

**Answer:**  
**Microsoft Defender Antivirus**, which can detect threats and **quarantine** them.
