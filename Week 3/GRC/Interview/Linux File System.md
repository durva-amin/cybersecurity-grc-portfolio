# Interview Questions

### Q1. What is the Linux file system?

**Answer:**  
It is the hierarchical structure Linux uses to organize and manage files and directories.

### Q2. What is the root directory in Linux?

**Answer:**  
`/` is the **root directory**, which is the starting point of the Linux file system hierarchy.

### Q3. Where are normal users' home directories stored?

**Answer:**  
Usually under **`/home`**.

### Q4. Where are Linux configuration files commonly stored?

**Answer:**  
In **`/etc`**.

### Q5. Where are many Linux logs stored?

**Answer:**  
Under **`/var/log`**.

### Q6. What is `/proc`?

**Answer:**  
`/proc` is a virtual filesystem that provides information about **processes and the running kernel/system**.

### Q7. What is the difference between `/root` and `/`?

**Answer:**  
`/` is the **root of the entire file system**, while `/root` is the **home directory of the root user**.

# Scenario-Based Question

### Q. A security analyst wants to investigate system logs on a Linux server. Which directory would they commonly check?

**Answer:**  
**`/var/log`**, because it commonly contains system and application log files.
