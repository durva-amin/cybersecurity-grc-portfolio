# Interview Questions

### Q1. What is Windows Firewall?

**Answer:**  
Windows Firewall is a built-in Windows security feature that monitors and controls network traffic based on configured security rules.

### Q2. What is the main purpose of Windows Firewall?

**Answer:**  
To control network connections and help prevent unauthorized network access to the computer.

### Q3. Can Windows Firewall block specific ports?

**Answer:**  
Yes. Firewall rules can allow or block traffic based on **port numbers**, along with other conditions.

### Q4. Can Windows Firewall control application traffic?

**Answer:**  
Yes. Firewall rules can be configured to allow or block network traffic associated with specific applications.

### Q5. What are the Windows Firewall network profiles?

**Answer:**  
The main profiles are **Domain, Private, and Public**.

### Q6. Is Windows Firewall an antivirus?

**Answer:**  
No. Windows Firewall controls network traffic, while **Microsoft Defender Antivirus** provides malware protection.

# Scenario-Based Question

### Q. An employee connects their laptop to public Wi-Fi. The organization wants to reduce unauthorized incoming network connections. Which Windows security feature can help?

**Answer:**  
**Windows Firewall**, especially by applying appropriate rules for the **Public** network profile.
