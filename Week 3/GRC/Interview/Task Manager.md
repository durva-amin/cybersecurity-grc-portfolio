# Interview Questions

### Q1. What is Task Manager?

**Answer:**  
Task Manager is a built-in Windows tool used to view and manage running processes, applications, users, services, and system resource usage.

### Q2. What can you monitor using Task Manager?

**Answer:**  
You can monitor **CPU, memory, disk, network, and GPU usage**, along with running processes and applications.

### Q3. How can Task Manager help in cybersecurity?

**Answer:**  
It can help identify unusual processes or resource usage during basic troubleshooting and security investigation.

### Q4. What is the Startup Apps section used for?

**Answer:**  
It shows applications that automatically start with Windows and allows users to enable or disable their startup behavior.

### Q5. Can Task Manager detect malware?

**Answer:**  
Task Manager can help identify **suspicious processes**, but it is not an antivirus and cannot reliably detect all malware.

# Scenario-Based Question

### Q. A user's computer suddenly becomes extremely slow. You suspect that an unknown process is consuming a large amount of CPU. Which Windows tool would you check first?

**Answer:**  
**Task Manager**, particularly the **Processes** tab, to check CPU usage and identify the process.
