## Definition

**Linux** is an open-source operating system kernel. Linux-based operating systems, called **Linux distributions (distros)**, combine the Linux kernel with other software to provide a complete operating system.

**Simple Definition:**

> Linux is an open-source operating system platform widely used on **servers, computers, cloud systems, and security devices**.

---

## What is a Linux Distribution?

A **Linux distribution** is a complete operating system built around the Linux kernel.

Examples:

- **Ubuntu**
- Debian
- Fedora
- Kali Linux
- Red Hat Enterprise Linux (RHEL)

For your project, you will be using **Ubuntu**.

---

## Important Features of Linux

### 1. Open Source

Its source code is available for people to inspect, modify, and distribute according to its license.

### 2. Multiuser

Multiple users can use the same Linux system with separate accounts and permissions.

### 3. Multitasking

Linux can run multiple processes at the same time.

### 4. Secure Permission System

Linux uses users, groups, and file permissions to control access to resources.

### 5. Command-Line Interface

Linux provides a **terminal/shell** where users can execute commands.

Example:

pwd

This displays your current directory.

## Linux and Cybersecurity

Linux is important in cybersecurity because it is widely used for:

- Servers
- Cloud infrastructure
- Security tools
- Network devices
- Security testing
- System administration

Security professionals often need to understand Linux commands, permissions, processes, and logs.

## Linux vs Windows

|Linux|Windows|
|---|---|
|Open-source kernel|Proprietary operating system|
|Commonly managed through terminal and GUI|Commonly managed through GUI and PowerShell/Command Prompt|
|Strong user/group permission model|Uses accounts and access controls|
|Widely used on servers|Widely used on desktops|
|Many distributions available|Windows editions available|
