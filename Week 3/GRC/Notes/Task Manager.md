## Definition

**Windows Task Manager** is a built-in Windows tool used to **view and manage running applications, processes, system performance, and resource usage**.

**Simple Definition:**

> Task Manager helps you see **what is running on your computer and how much system resources it is using**.

---

## What Does Task Manager Show?

Task Manager can show:

- Running applications
- Background processes
- CPU usage
- Memory (RAM) usage
- Disk usage
- Network usage
- Startup applications
- Users currently logged in
- Services

---

## Important Tabs

### 1. Processes

Shows running applications and background processes.

You can see their:

- CPU usage
- Memory usage
- Disk usage
- Network usage

### 2. Performance

Shows overall system resource usage such as:

- CPU
- Memory
- Disk
- Network
- GPU

### 3. Startup Apps

Shows applications that automatically start when Windows starts.

You can disable unnecessary startup applications.

### 4. Users

Shows users currently signed in and their resource usage.

### 5. Details

Provides more detailed information about running processes.

### 6. Services

Shows Windows services and their current status.

---

## Why is Task Manager Useful in Cybersecurity?

Task Manager can help with **basic investigation**.

For example, if you notice that your computer suddenly becomes very slow, you can check Task Manager for a process using unusually high CPU or memory.

An unfamiliar process may require further investigation, although **an unfamiliar process is not automatically malware**.
