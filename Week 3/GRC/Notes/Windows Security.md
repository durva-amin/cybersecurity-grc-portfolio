## Definition

**Windows Security** is the built-in security system in Windows that provides tools to **protect a computer from malware, unauthorized access, and other security threats**.

**Simple Definition:**

> Windows Security is a collection of built-in Windows security features used to **protect and monitor a computer**.

---

## What Does Windows Security Provide?

Windows Security includes several protection areas, such as:

- **Virus & threat protection** → Helps detect and remove malware.
- **Firewall & network protection** → Controls network connections.
- **App & browser control** → Helps protect against malicious or unsafe apps and websites.
- **Device security** → Provides hardware and system-level security features.
- **Account protection** → Helps protect user accounts and sign-in security.

---

## Why is Windows Security Important?

It helps protect a Windows computer from:

- Malware
- Unauthorized network connections
- Malicious applications
- Unsafe websites and downloads
- Unauthorized access
