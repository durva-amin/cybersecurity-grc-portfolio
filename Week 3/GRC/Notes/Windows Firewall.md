## Definition

**Windows Firewall** is a built-in Windows security feature that **monitors and controls network traffic entering and leaving your computer based on security rules**.

**Simple Definition:**

> Windows Firewall acts like a **security gate for your computer's network connections**.

---

## What Does Windows Firewall Do?

It can:

- Allow or block network connections.
- Control incoming and outgoing traffic.
- Protect your computer from unauthorized network access.
- Apply rules based on applications, ports, IP addresses, and protocols.
- Help reduce exposure to network-based threats.

---

## How Does It Work?

When a network connection reaches your computer:

1. Windows Firewall checks the connection.
2. It compares it with configured firewall rules.
3. If the connection is allowed → **Permit ✅**
4. If it is blocked → **Deny ❌**

**Simple flow:**

**Network Traffic → Windows Firewall → Check Rules → Allow / Block**


## Windows Firewall Profiles

Windows commonly uses different network profiles:

### Domain

Used when the computer is connected to an organization's domain network.

### Private

Used for trusted networks such as your home network.

### Public

Used for untrusted networks such as public Wi-Fi.

The firewall can apply different rules depending on the network profile.
