# Quick Revision

- **`sudo` = Superuser do**
- Used to run commands with **elevated privileges**.
- Usually runs commands as **root**.
- Only **authorized users** can use it.
- Helps implement **least privilege**.
- Useful for administrative tasks.
- Safer than routinely working directly as root.

### ⭐ Easy Trick

> **Normal user + `sudo` → Temporary administrative power**

**`chmod` → Change permissions**  
**`chown` → Change ownership**  
**`sudo` → Run administrative commands**
