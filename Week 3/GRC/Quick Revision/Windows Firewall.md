# Quick Revision

- **Windows Firewall = Network traffic protection**
- Controls **incoming and outgoing connections**.
- Uses **firewall rules**.
- Can filter based on:
    - Applications
    - Ports
    - IP addresses
    - Protocols
- Profiles:
    - **Domain**
    - **Private**
    - **Public**
- **Firewall ≠ Antivirus**

### ⭐ Easy Trick

**Defender Antivirus → Protects against malware 🦠**

**Windows Firewall → Controls network traffic 🌐**

> **Firewall = Network security gate**
