# Quick Revision

- **Linux User = Identity + Access**
- **Root → UID 0 → Highest privileges**
- **Normal user → Limited privileges**
- **Service user → Used by applications/services**
- **UID → User ID**
- `/home` → Normal users' home directories
- `whoami` → Current user
- `id` → UID, GID, groups
- `who` → Logged-in users
- **Least privilege → Give only necessary access**

### ⭐ Easy Trick

**User → Who are you?**  
**UID → Your numerical identity**  
**Root → Full administrative power**  
**Normal user → Limited access**
