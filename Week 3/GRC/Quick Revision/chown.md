# Quick Revision

### `chown`

**→ Change ownership**

sudo chown user file

**Change owner + group:**

sudo chown user:group file

**Recursive:**

sudo chown -R user:group directory/

### ⭐ Easy Trick

> **`chmod` = Who can do what?**  
> **`chown` = Who owns it?**

**chmod → Permissions 🔐**  
**chown → Ownership 👤**
