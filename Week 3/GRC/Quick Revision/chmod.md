# Quick Revision

**`chmod` → Change file permissions**

### Numeric

- `r = 4`
- `w = 2`
- `x = 1`

### Categories

- `u` → Owner
- `g` → Group
- `o` → Others
- `a` → All

### Examples

chmod 755 file

chmod u+x script.sh

chmod o-w file.txt

### ⭐ Easy Trick

> **chmod = Change permissions**

**4 Read 📖 + 2 Write ✍️ + 1 Execute ▶️**
