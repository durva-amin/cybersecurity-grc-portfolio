# Quick Revision

- **Windows Defender = Microsoft Defender Antivirus**
- Built into Windows.
- Protects against **malware**.
- Provides **real-time protection**.
- Can perform different types of scans.
- Can **detect, block, quarantine, or remove** threats.
- **Windows Security ≠ Defender**
    - Windows Security = Security dashboard/interface
    - Defender Antivirus = Antivirus protection

### ⭐ Easy Trick

**Windows Security → Security dashboard 🛡️**

**Defender Antivirus → Finds and fights malware 🔍🦠**
