# Quick Revision

- **`ps` = Process Status**
- Shows a **snapshot** of running processes.
- `ps` → Current terminal/session processes
- `ps aux` → Detailed processes from all users
- `ps -ef` → Detailed process information including PPID
- **PID → Process ID**
- **PPID → Parent Process ID**
- `ps` is useful for **process investigation**.

### ⭐ Easy Trick

> **`ps` = "Show me what is running."**

**`ps` → Snapshot 📋**  
**`top` → Real-time monitoring 📊**
