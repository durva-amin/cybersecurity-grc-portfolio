# Quick Revision

- **`top` = Real-time process monitoring**
- Shows:
    - PID
    - CPU usage
    - Memory usage
    - User
    - Processes
    - System load
- Continuously updates.
- Press **`q`** to exit.
- **`ps` → Snapshot**
- **`top` → Real-time monitoring**

### ⭐ Easy Trick

> **`ps` = Picture 📸 of processes**  
> **`top` = Live view 📊 of processes**
