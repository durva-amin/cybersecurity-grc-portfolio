# Quick Revision

- **Event Viewer = View and analyze Windows logs**
- Helps with **troubleshooting and security investigation**.
- Important logs:
    - **Application**
    - **Security**
    - **System**
    - **Setup**
    - **Forwarded Events**
- Event levels include:
    - Information
    - Warning
    - Error
    - Critical
- **Event Viewer records and shows events. It does not itself prevent attacks.**

### ⭐ Easy Trick

> **Event Viewer = "What happened on this computer?"**

**Security log → Security events**  
**System log → System events**  
**Application log → Application events**
