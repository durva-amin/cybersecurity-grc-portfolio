# Quick Revision

- **Process = Running program**
- Every process has a **PID**.
- **Parent process → Creates child process**
- Common states:
    - Running
    - Sleeping
    - Stopped
    - Zombie
- `ps` → View processes
- `top` → Monitor processes in real time
- `kill` → Send a signal to a process
- Processes are important for **system monitoring and security investigation**.

### ⭐ Easy Trick

> **Program = Stored instructions**  
> **Process = Program currently running**

**PID = Process's identification number**
