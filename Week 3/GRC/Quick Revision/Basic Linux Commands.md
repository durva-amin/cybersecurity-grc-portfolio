# Quick Revision

Remember these first:

pwd     → Where am I?

ls      → What is here?

cd      → Go somewhere

mkdir   → Create folder

touch   → Create file

cat     → Read file

cp      → Copy

mv      → Move/Rename

rm      → Delete

grep    → Search text

find    → Find files

whoami  → Who am I?

ps      → Processes

top     → Live process monitoring

kill    → Stop/control process

chmod   → Permissions

chown   → Ownership

sudo    → Elevated privileges

### ⭐ Easy Trick

Think of basic Linux commands as a simple workflow:

**Navigate → `pwd`, `ls`, `cd`**

**Create → `mkdir`, `touch`**

**Manage → `cp`, `mv`, `rm`**

**Read/Search → `cat`, `grep`, `find`**

**System → `ps`, `top`, `kill`**

**Security → `chmod`, `chown`, `sudo`**
