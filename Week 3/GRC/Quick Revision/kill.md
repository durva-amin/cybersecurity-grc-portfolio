# Quick Revision

- **`kill` → Sends a signal to a process**
- Uses **PID**
- `kill PID` → Sends **SIGTERM (15)**
- `kill -9 PID` → Sends **SIGKILL (9)**
- **SIGTERM → Graceful termination**
- **SIGKILL → Immediate termination**
- Find processes using **`ps` or `top`**

### ⭐ Easy Trick

> **`ps` → Find it**  
> **`top` → Monitor it**  
> **`kill` → Stop it**
