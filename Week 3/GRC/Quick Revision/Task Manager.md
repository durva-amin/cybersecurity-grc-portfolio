# Quick Revision

- **Task Manager = Monitor and manage running processes**
- Shows:
    - CPU
    - RAM
    - Disk
    - Network
    - GPU
- **Processes** → Running programs/processes
- **Performance** → Resource usage
- **Startup Apps** → Programs starting with Windows
- **Services** → Windows services
- Useful for **basic troubleshooting and security investigation**.

### ⭐ Easy Trick

> **Task Manager = "What is running and what is using my resources?"**
