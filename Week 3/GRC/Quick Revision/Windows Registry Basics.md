# Quick Revision

- **Windows Registry = Configuration database**
- Stores settings for:
    - Windows
    - Users
    - Applications
    - Hardware
- Structure:
    - **Keys**
    - **Subkeys**
    - **Values**
- Important hives:
    - **HKLM** → Computer/system
    - **HKCU** → Current user
    - **HKCR** → File associations/classes
    - **HKU** → User profiles
    - **HKCC** → Current hardware profile
- Open with **`regedit`**
- Important in **security investigations and malware persistence analysis**.
