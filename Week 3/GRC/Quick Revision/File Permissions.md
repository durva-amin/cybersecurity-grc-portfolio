# Quick Revision

### Permissions

**`r` → Read → 4**

**`w` → Write → 2**

**`x` → Execute → 1**

### Categories

**u → User/Owner**

**g → Group**

**o → Others**

### Example

rwxr-xr--

= **754**

### ⭐ Easy Trick

Remember:

**4 = Read** 📖  
**2 = Write** ✍️  
**1 = Execute** ▶️

And:

> **User → Group → Others**

This is one of the **most important Linux concepts for cybersecurity interviews**, so make sure you can read a permission string like `-rwxr-xr--` without calculating for too long.
