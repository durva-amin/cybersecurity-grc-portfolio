# Quick Revision

- Linux uses a **hierarchical file system**.
- `/` = **Root directory**
- `/home` = Normal users' home directories
- `/root` = Root user's home directory
- `/etc` = Configuration
- `/var/log` = Logs
- `/tmp` = Temporary files
- `/proc` = Process/system information
- `/boot` = Boot-related files
- `/dev` = Device files

### ⭐ Easy Trick

Remember the most important ones:

**`/` → Everything starts here**

**`/home` → Users**

**`/etc` → Configuration**

**`/var/log` → Logs**

**`/proc` → Processes/system information**
