# Quick Revision

- **Group = Collection of users**
- Used for **permission and access management**.
- **Primary group** → Main group associated with a user.
- **Secondary group** → Additional group memberships.
- `groups` → Shows groups.
- `id` → Shows UID, GID, and groups.
- `groupadd` → Creates a group.
- `usermod -aG` → Adds a user to a group.
- Groups help implement **least privilege**.

### ⭐ Easy Trick

**User → Individual account**

**Group → Collection of users**

**Group permissions → One permission setup for multiple users**
