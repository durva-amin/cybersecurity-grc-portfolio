# Quick Revision

- **Windows Security = Built-in Windows security interface**
- Provides multiple security features.
- Important areas:
    - Virus & threat protection
    - Firewall & network protection
    - App & browser control
    - Device security
    - Account protection
- Helps protect against **malware, network threats, unsafe apps, and unauthorized access**.
