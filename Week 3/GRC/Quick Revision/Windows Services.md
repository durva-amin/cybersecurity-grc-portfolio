# Quick Revision

- **Windows Services = Background programs**
- Perform system/application tasks.
- Can run automatically or manually.
- Common states:
    - Running
    - Stopped
    - Paused
- Startup types:
    - Automatic
    - Automatic (Delayed Start)
    - Manual
    - Disabled
- Managed through **`services.msc`**
- Important during **security investigations and persistence analysis**.

### ⭐ Easy Trick

> **Service = Background worker**

**Windows starts → Service runs in background → Performs its assigned task**
