# Quick Revision

- **Linux = Open-source kernel**
- **Ubuntu = Linux distribution**
- Linux is widely used in **servers and cloud environments**.
- Supports **multiple users and processes**.
- Has a strong **permissions system**.
- Provides a **terminal/command line**.
- Important for **cybersecurity and system administration**.

### ⭐ Easy Trick

**Linux → Kernel**

**Ubuntu → Distribution**

**Terminal → Commands**

**Users + Groups + Permissions → Access Control**
