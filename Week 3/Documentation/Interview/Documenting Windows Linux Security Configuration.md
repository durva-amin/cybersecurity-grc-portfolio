### Interview Questions

**Q1. Why is security configuration documented?**  
**Answer:** To record the current security settings, support audits, and help verify that security controls are properly configured.

**Q2. What security configurations can be documented?**  
**Answer:** Firewall settings, user accounts, permissions, security tools, system updates, and other relevant security controls.

**Q3. Why is configuration documentation useful in GRC?**  
**Answer:** It provides evidence of security controls and helps with compliance reviews and audits.

### Scenario-Based Question

**Q. During an audit, you need to verify whether Windows Firewall is enabled on a system. How would you document it?**

**Answer:** Record the firewall status and include a screenshot or other appropriate evidence showing the configuration.
