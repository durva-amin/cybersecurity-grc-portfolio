### Interview Questions

**Q1. What is a security procedure?**  
**Answer:** A security procedure provides step-by-step instructions for performing a security-related task.

**Q2. What should a security procedure contain?**  
**Answer:** It can include prerequisites, step-by-step instructions, expected results, security considerations, and evidence.

**Q3. Why are security procedures important?**  
**Answer:** They ensure security tasks are performed consistently and correctly.

### Scenario-Based Question

**Q. Your organization wants every employee to follow the same process when reporting a suspected phishing email. What should you create?**

**Answer:** A documented security procedure describing the required steps for identifying and reporting the phishing email.
