### Interview Questions

**Q1. What is a step-by-step procedure?**  
**Answer:** It is a documented sequence of instructions that explains how to perform a specific task.

**Q2. Why should security procedures be written step by step?**  
**Answer:** They make the task consistent, repeatable, and easier to follow correctly.

**Q3. What makes a good procedure?**  
**Answer:** It should be clear, ordered, specific, and easy for the intended user to follow.

### Scenario-Based Question

**Q. Two employees perform the same security configuration differently because there are no documented instructions. How can this be improved?**

**Answer:** Create a clear step-by-step procedure so both employees follow the same documented process.
