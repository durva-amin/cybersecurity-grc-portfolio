### Interview Questions

**Q1. Why are screenshots used as evidence?**  
**Answer:** They provide visual proof that supports a documented observation or finding.

**Q2. What should you check before using a screenshot as evidence?**  
**Answer:** It should be relevant, clear, readable, and directly support the observation.

**Q3. Can any screenshot be considered security evidence?**  
**Answer:** No. The screenshot should be relevant to the finding and provide sufficient information to support it.

### Scenario-Based Question

**Q. You report that a security setting is disabled and attach a screenshot showing the setting. What purpose does the screenshot serve?**

**Answer:** It provides evidence supporting the observation that the security setting is disabled.
