### Interview Questions

**Q1. What is an expected result in a security procedure?**  
**Answer:** It describes the outcome that should occur when the procedure is completed correctly.

**Q2. Why is an expected result important?**  
**Answer:** It helps verify whether the procedure was completed successfully.

**Q3. What is the difference between a procedure and an expected result?**  
**Answer:** A procedure explains **what to do**, while the expected result explains **what should happen afterward**.

### Scenario-Based Question

**Q. You document a procedure to enable a security setting. How can you verify that the procedure worked?**

**Answer:** Check whether the actual result matches the documented expected result.
