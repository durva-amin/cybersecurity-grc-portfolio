### Interview Questions

**Q1. What is evidence in a security assessment?**  
**Answer:** Evidence is information or proof that supports an observation, finding, or conclusion.

**Q2. Why is evidence important?**  
**Answer:** It makes security findings more reliable and helps demonstrate that an observation is based on facts.

**Q3. What can be used as security evidence?**  
**Answer:** Screenshots, configuration records, logs, documents, system outputs, and other relevant information.

### Scenario-Based Question

**Q. You identify that a security setting is disabled. What should you provide to support this observation?**

**Answer:** Relevant evidence, such as a screenshot or configuration record showing that the setting is disabled.
