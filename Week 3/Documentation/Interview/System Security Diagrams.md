### Interview Questions

**Q1. What is a security diagram?**  
**Answer:** A security diagram is a visual representation of system components, connections, and security controls.

**Q2. Why are security diagrams useful?**  
**Answer:** They help organizations understand the security architecture and identify possible security weaknesses.

**Q3. What can be shown in a security diagram?**  
**Answer:** Systems, servers, users, networks, security controls, connections, and data flow.

### Scenario-Based Question

**Q. An organization wants to show where its firewall, servers, users, and Internet connection are located in its network. What should it create?**

**Answer:** A system or security diagram showing the components, their connections, and relevant security controls.
