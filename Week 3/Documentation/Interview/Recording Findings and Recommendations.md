### Interview Questions

**Q1. What is a security finding?**  
**Answer:** A security finding is an identified issue or weakness that requires attention.

**Q2. What should be included when recording a finding?**  
**Answer:** The observation, supporting evidence, impact, and recommendation.

**Q3. Why should findings and recommendations be documented?**  
**Answer:** Documentation helps organizations understand security issues and track actions needed to address them.

### Scenario-Based Question

**Q. During a security review, you find that a system has an outdated security configuration. How should you record it?**

**Answer:** Document the observation, provide supporting evidence, explain the potential impact, and recommend an appropriate corrective action.
