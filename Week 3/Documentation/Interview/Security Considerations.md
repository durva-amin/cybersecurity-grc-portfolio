### Interview Questions

**Q1. What are security considerations in a procedure?**  
**Answer:** They are security precautions and risks that should be considered while performing the procedure.

**Q2. Why are security considerations important?**  
**Answer:** They help prevent security weaknesses, mistakes, and unintended security risks during a procedure.

**Q3. What can security considerations include?**  
**Answer:** Access permissions, protection of sensitive information, security risks, and precautions that should be followed.

### Scenario-Based Question

**Q. A procedure requires administrator access to change a security setting. What security consideration should be documented?**

**Answer:** Administrator access should be limited to authorized users and should not be shared with others.
