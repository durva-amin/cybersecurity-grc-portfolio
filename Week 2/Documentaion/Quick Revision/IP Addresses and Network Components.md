**IP Address → Identifies a device on a network.**

Common network components:

- Router → Connects networks
- Switch → Connects devices
- Firewall → Controls traffic
- Server → Provides services
- Endpoint → User device




### Interview Tip

Don't say an IP address is the **physical address** of a device.

An IP address is a **logical network address**. A MAC address is associated with the network interface at the hardware/link layer.
