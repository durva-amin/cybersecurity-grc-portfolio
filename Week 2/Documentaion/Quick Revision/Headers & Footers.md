**Header → Top of page**

- Page number

- Classification

**Main benefit → Professional + identifiable documentation**



## Interview Tip

Don't confuse **Header/Footer** with the document's main content.

Headers and Footers contain **repeated document-control or identification information**, while the main body contains the actual technical or security content.

### 🔑 Easy Trick to Remember

**Header = Head → Top** ⬆️  
**Footer = Foot → Bottom** ⬇️
