**Page Break → New page**

**Section Break → New section + different formatting**

**Ctrl + Enter → Page Break**

## Interview Tip

A common mistake is using **many Enter keys** to move content to the next page.

Don't do this in professional documentation.

Use:

> **Ctrl + Enter = Page Break**

It keeps your document clean and ensures the layout doesn't break when you add or remove content.
