## Interview Questions

### Q1. What structure can you use to explain a technical concept?

**Answer:**  
A useful structure is **Definition → Explanation → Example**.

### Q2. Why should you include an example in technical documentation?

**Answer:**  
An example connects the technical concept to a practical situation and makes it easier to understand.

### Q3. What should come first when explaining a technical concept?

**Answer:**  
Start with a short and accurate definition, followed by an explanation and example.

## Scenario-Based Question

**Q.** You need to document HTTPS for employees who have basic technical knowledge. How would you structure the explanation?

**Answer:**

**Definition:** HTTPS is a secure version of HTTP that protects communication between a browser and a web server.

**Explanation:** It uses encryption to help protect data transmitted between them.

**Example:** When you log in to an online banking website using HTTPS, the connection helps protect your login information from being read in transit.
