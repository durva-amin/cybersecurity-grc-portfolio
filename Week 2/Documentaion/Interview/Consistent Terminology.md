## Interview Questions

### Q1. What is consistent terminology?

**Answer:**  
Consistent terminology means using the same terms and wording throughout a document when referring to the same concept.

### Q2. Why is consistent terminology important?

**Answer:**  
It reduces confusion, improves clarity, and makes technical documentation easier to understand.

### Q3. What can happen if terminology is inconsistent?

**Answer:**  
Readers may think different terms refer to different systems, devices, or concepts, which can cause confusion.

---

## Scenario-Based Question

**Q.** A network document uses "router," "gateway," and "network device" interchangeably for the same device. What documentation problem does this create?

**Answer:**  
**Inconsistent terminology**, which can cause confusion about whether the terms refer to the same or different devices.
