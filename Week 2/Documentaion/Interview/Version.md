## Interview Questions

### Q1. What is a document version?

**Answer:**  
A document version identifies the current release of a document and helps track changes made to it.

### Q2. Why is version control important in GRC?

**Answer:**  
It ensures users are working with the correct and latest approved document and provides a history of document changes.

### Q3. What does Version 1.1 usually indicate?

**Answer:**  
It usually indicates a minor update or correction to Version 1.0.

### Q4. What does Version 2.0 usually indicate?

**Answer:**  
It usually indicates a major revision or significant change.

---

## Scenario-Based Question

**Q.** An employee is using Version 1.0 of a security policy, but Version 2.0 has already been approved. What is the problem?

**Answer:**  
The employee is using an outdated version. They should use the latest approved version, Version 2.0.
