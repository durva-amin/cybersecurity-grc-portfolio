## Interview Questions

### Q1. What is an IP Address?

**Answer:**  
An IP address is a logical address used to identify a device and enable communication on a network.

### Q2. What is a network component?

**Answer:**  
A network component is a device or element that helps a network communicate and operate, such as a router, switch, firewall, or server.

### Q3. Why is IP information useful in GRC?

**Answer:**  
It helps document network assets and understand the organization's network environment during risk assessments and audits.

### Q4. What is the difference between a router and a switch?

**Answer:**  
A **router connects different networks**, while a **switch connects devices within a network**.

## Scenario-Based Question

**Q.** During a network assessment, you are given a list containing device names, IP addresses, and device types. What type of information is this?

**Answer:**  
It is **network asset information**, which can help understand and document the organization's network environment.
