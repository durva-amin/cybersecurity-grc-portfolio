## Interview Questions

### Q1. What is Version History?

**Answer:**  
Version History is a record of the different versions of a document and the changes made to each version.

### Q2. Why is Version History important in GRC?

**Answer:**  
It provides traceability of document changes and helps demonstrate proper document control during audits.

### Q3. What information is usually included in Version History?

**Answer:**  
Version number, date, author, and description of changes.

### Q4. What is the difference between Version and Version History?

**Answer:**  
**Version** identifies the current version of a document, while **Version History** records the previous versions and changes made over time.

## Scenario-Based Question

**Q.** An auditor asks, "When was this security policy changed, who changed it, and what was changed?" Where would you look?

**Answer:**
