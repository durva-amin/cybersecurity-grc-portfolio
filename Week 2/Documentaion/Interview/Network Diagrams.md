## Interview Questions

### Q1. What is a Network Diagram?

**Answer:**  
A Network Diagram is a visual representation of network devices and the connections between them.

### Q2. Why is a network diagram important for GRC?

**Answer:**  
It helps GRC professionals understand the organization's network environment, identify security controls, and recognize potential security risks.

### Q3. What components can be shown in a network diagram?

**Answer:**  
Internet, firewall, router, switch, servers, computers, access points, and their connections.

### Q4. What is the purpose of a network diagram during an audit?

**Answer:**  
It provides an overview of the network environment and helps auditors understand the systems, devices, connections, and security controls.

## Scenario-Based Question

**Q.** During a security assessment, you need to understand how the company's internet connection reaches its internal servers and employee computers. What document would help you?

**Answer:**  
A **Network Diagram**, because it visually shows the network devices and how they are connected.
