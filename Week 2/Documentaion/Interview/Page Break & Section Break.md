## Interview Questions

### Q1. What is a Page Break?

**Answer:**  
A Page Break starts the following content on a new page.

### Q2. What is a Section Break?

**Answer:**  
A Section Break divides a document into sections that can have different formatting or page settings.

### Q3. What is the difference between Page Break and Section Break?

**Answer:**  
A Page Break only starts content on a new page, while a Section Break creates a new section that can have different formatting.

### Q4. When would you use a Section Break?

**Answer:**  
When different parts of a document need different page orientation, headers, footers, margins, or other formatting.

---

## Scenario-Based Question

**Q.** Your network diagram is very wide, so you want only that page in Landscape orientation while keeping the rest of the document Portrait. What should you use?

**Answer:**  
**Section Break**, because it allows that part of the document to have different page orientation.
