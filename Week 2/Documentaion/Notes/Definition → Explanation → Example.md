## Definition

A good technical document can explain a concept using three simple parts:

**Definition → Explanation → Example**

### Simple Definition

First tell the reader **what it is**, then **how it works**, then give a **real-life example**.

---

## The 3-Part Structure

### 1. Definition

Give a short and accurate meaning.

**Example:**

> **DNS is a system that translates domain names into IP addresses.**

### 2. Explanation

Explain how or why it works.

> When a user enters a website name, DNS helps the device find the IP address associated with that name.

### 3. Example

Connect it to a real situation.

> For example, when you enter `google.com`, DNS helps your device find the server's IP address.

---

## Why is This Structure Important?

- Makes technical concepts easier to understand.
- Keeps explanations organized.
- Helps non-technical readers.
- Makes documentation consistent.
- Reduces unnecessary technical detail.
