## Definition

**Styles** are predefined formatting settings in Microsoft Word that make text consistent throughout a document.

**Headings** are styles used to organize a document into different sections and subsections.

### Simple Definition

**Styles = Consistent formatting**  
**Headings = Organizing the document**

---

## Why are Styles & Headings Important?

- Keep formatting consistent.
- Make documents easier to read.
- Create a clear document structure.
- Make navigation easier.
- Help automatically create a **Table of Contents**.
- Make it easier to update formatting across the document.

---

## Common Heading Styles

- **Title** → Main document title
- **Heading 1** → Main sections
- **Heading 2** → Subsections
- **Heading 3** → Smaller subsections

### Example

**Heading 1:** Network Devices

**Heading 2:** Router

**Heading 2:** Switch

**Heading 1:** Network Protocols

**Heading 2:** HTTP

**Heading 2:** HTTPS
