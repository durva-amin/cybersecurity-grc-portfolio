## Definition

**Page Break** starts the next content on a new page.

**Section Break** divides a document into separate sections so each section can have different formatting or page settings.

### Simple Definition

**Page Break = Start a new page.**  
**Section Break = Create a new section with different formatting.**

---

## Why are Page Breaks & Section Breaks Important?

- Keep documents organized.
- Prevent headings from appearing at the bottom of a page.
- Separate major sections.
- Allow different headers, footers, margins, or page orientation.
- Make technical documents more professional.

---

## Page Break

Use a **Page Break** when you simply want the next content to start on a new page.

### Example

Your Week 2 document could have:

**Page 1:** Purpose & Scope  
**Page 2:** Network Diagram  
**Page 3:** OSI/TCP-IP Overview

Instead of pressing Enter many times to move content down, use **Page Break**.

### In Word

**Insert → Page Break**

Shortcut:

**Ctrl + Enter**

---

## Section Break

Use a **Section Break** when different parts of the document need different formatting.

For example:

- One section uses **Portrait** orientation.
- Another section uses **Landscape** orientation for a large network diagram.
- Different sections need different headers or footers.

### In Word

**Layout → Breaks → Section Breaks**

Common option:

**Next Page** → Starts a new section on the next page.
