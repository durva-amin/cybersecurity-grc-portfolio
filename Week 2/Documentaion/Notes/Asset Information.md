## Definition

**Asset Information** is information about the systems, devices, applications, data, and other resources that an organization owns or uses.

### Simple Definition

**Asset Information = Details about an organization's important resources.**

---

## Why is Asset Information Important?

- Helps organizations know what assets they have.
- Supports risk assessment.
- Helps identify which assets need protection.
- Makes security monitoring easier.
- Supports audits and compliance.

---

## Common Asset Information

For a network device, you might document:

- Asset Name
- Asset Type
- IP Address
- Location
- Owner
- Purpose
- Security Status

### Example

|Asset Name|Type|IP Address|Owner|Purpose|
|---|---|---|---|---|
|Main Router|Network Device|192.168.1.1|IT Team|Connects internal network to Internet|
