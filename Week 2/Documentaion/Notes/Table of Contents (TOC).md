## Definition

A **Table of Contents (TOC)** is a list of the main headings and subheadings in a document, along with their page numbers.

### Simple Definition

**Table of Contents = A map of the document.**

---

## Why is a Table of Contents Important?

- Makes long documents easier to navigate.
- Shows the document structure.
- Helps readers quickly find specific sections.
- Makes technical documentation more professional.
- Can be automatically updated when content changes.

---

## How Does Word Create a TOC?

Word uses **Heading Styles** to create it.

For example:

**Heading 1:** Network Devices  
**Heading 2:** Router  
**Heading 2:** Switch  
**Heading 1:** Network Protocols  
**Heading 2:** HTTP  
**Heading 2:** HTTPS

Word can use these headings to automatically create the TOC
