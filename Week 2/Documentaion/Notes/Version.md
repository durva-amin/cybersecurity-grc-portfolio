## Definition

**Version** identifies the current state or release of a document and helps track changes made to it over time.

### Simple Definition

**Version = Identifies which edition of the document you are using.**

---

## Why is Version Important?

- Helps identify the latest document.
- Prevents confusion between old and new versions.
- Supports document control.
- Helps track changes.
- Provides evidence during audits.

---

## Common Version Numbers

### Version 1.0

First official release.

### Version 1.1

Minor update or correction.

### Version 2.0

Major revision or significant change.
