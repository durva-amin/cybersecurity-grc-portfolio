## Definition

A **Network Diagram** is a visual representation of network devices and how they are connected to each other.

### Simple Definition

**Network Diagram = A picture showing network devices and their connections.**

---

## Why are Network Diagrams Important?

- Shows how a network is structured.
- Helps understand connections between devices.
- Makes network documentation easier to understand.
- Helps identify security controls and possible risks.
- Useful during troubleshooting and security assessments.

---

## Common Components

A basic network diagram may include:

- Internet
- Firewall
- Router
- Switch
- Servers
- Computers
- Wireless Access Point
- Network connections

### Example

```
Internet
   ↓
Firewall
   ↓
Router
   ↓
```
