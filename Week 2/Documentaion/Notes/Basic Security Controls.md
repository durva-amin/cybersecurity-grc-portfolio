## Definition

**Security Controls** are measures used by an organization to **prevent, detect, or reduce security risks**.

### Simple Definition

**Security Controls = Measures used to protect systems, data, and networks.**

---

## Why are Security Controls Important?

- Protect systems and data.
- Reduce security risks.
- Prevent unauthorized access.
- Detect suspicious activity.
- Support compliance requirements.

---

## Common Basic Network Security Controls

### 1. Firewall

Controls incoming and outgoing network traffic based on security rules.

### 2. IDS

**Intrusion Detection System** monitors network activity and detects suspicious or malicious activity.

### 3. IPS

**Intrusion Prevention System** detects suspicious activity and can take action to block or prevent it.

### 4. VPN

Creates a secure connection over a network and helps protect data in transit.

### 5. Access Control

Ensures only authorized users can access systems or information.

### 6. Encryption

Converts data into a protected form so unauthorized people cannot easily read it.
