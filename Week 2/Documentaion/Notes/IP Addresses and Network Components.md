## Definition

**IP Address** is a unique logical address assigned to a device on a network so it can be identified and communicate with other devices.

**Network Components** are the devices and elements that help a network communicate and operate.

### Simple Definition

**IP Address = Address of a device on a network.**  
**Network Components = Devices that help the network work.**

---

## Why is this Important?

- Identifies devices on a network.
- Helps devices communicate.
- Helps understand network structure.
- Useful for network documentation and security assessments.
- Helps identify where security controls and risks may exist.

---

## Common Network Components

### Router

Connects different networks and forwards network traffic.

### Switch

Connects devices within a network and forwards data to the appropriate device.

### Firewall

Monitors and controls network traffic based on security rules.

### Server

Provides services or resources to other devices on a network.

### Client/Endpoint

A device such as a laptop or computer that accesses network resources.

---

## Example

|Device|Component|IP Address|
|---|---|---|
|Main Router|Router|192.168.1.1|
|Office Switch|Switch|192.168.1.2|
|File Server|Server|192.168.1.10|
|Employee PC|Endpoint|192.168.1.20|

This information helps document **which devices exist and how they are identified on the network**.
