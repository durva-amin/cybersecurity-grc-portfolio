## Definition

**Diagrams and screenshots** are visual elements used in technical documentation to explain systems, processes, configurations, or technical concepts more clearly.

### Simple Definition

**Diagrams = Show how something is connected or works.**  
**Screenshots = Show what something looks like or how to perform a task.**

---

## Why are Diagrams & Screenshots Important?

- Make technical concepts easier to understand.
- Show relationships between systems and components.
- Reduce the need for lengthy explanations.
- Help users follow technical procedures.
- Make documentation more practical.

---

## Diagrams

Use a **diagram** when you need to show:

- Network structure
- System architecture
- Data flow
- Processes
- Relationships between components

### Example

A basic network diagram could show:

**Internet → Firewall → Router → Switch → Computers**

This immediately shows how the components are connected.

---

## Screenshots

Use a **screenshot** when you need to show:

- A software setting
- A configuration
- A specific option in a tool
- Steps in a procedure
- An error message

### Example

If you're documenting how to configure a firewall rule, a screenshot can show where the rule is created and which settings need to be selected.
