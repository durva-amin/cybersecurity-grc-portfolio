## Definition

**SSH (Secure Shell)** is a network protocol used to **securely access and manage a remote computer or server over a network**.

**Simple Definition:**

> SSH allows you to **securely connect to and control a remote system**.

---

## What is SSH Used For?

SSH is commonly used for:

- Remote server administration.
- Secure remote login.
- Running commands on a remote system.
- Secure file transfer using related tools such as SFTP.
- Managing network devices.

---

## How SSH Works

A user connects from their computer to a remote server:

**Your Computer → 🔒 SSH Connection → Remote Server**

The connection is encrypted, helping protect information such as:

- Login credentials
- Commands
- Data exchanged during the session

---
