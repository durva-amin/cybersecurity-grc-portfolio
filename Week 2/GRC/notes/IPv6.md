## Definition

**IPv6 (Internet Protocol version 6)** is the newer version of the Internet Protocol that uses **128-bit addresses** to identify devices and enable communication over networks.

**Simple Definition:**

> IPv6 is a newer IP addressing system designed mainly to provide a **much larger number of IP addresses**.

---

## IPv6 Address Format

An IPv6 address has **128 bits** and is written using **8 groups of hexadecimal numbers**, separated by colons.

Example:

**2001:0db8:85a3:0000:0000:8a2e:0370:7334**

Each group contains **16 bits**.

So:

**8 groups × 16 bits = 128 bits**

---

## Why Was IPv6 Introduced?

The main reason was the **limited number of IPv4 addresses**.

IPv4 provides about **4.3 billion addresses**, while IPv6 provides an extremely large address space.

IPv6 also provides features such as:

- Larger address space
- Better support for modern networks
- Simplified address configuration
- Built-in support for multicast

---

## IPv6 Example

**2001:db8::1**

This is a shortened form of an IPv6 address.

IPv6 allows consecutive groups of zeros to be compressed using **`::`**.
