## Definition

A **Router** is a networking device that **connects different networks and forwards data packets between them** using IP addresses.

**Simple Definition:**

> A Router connects different networks and decides **where the data should go**.

---

## What Does a Router Do?

- Connects different networks.
- Forwards packets between networks.
- Uses **IP addresses** to make forwarding decisions.
- Acts as a **default gateway** for devices on a local network.
- Can provide Internet access to devices on a local network.

---

## How Does a Router Work?

1. A device sends data to another network.
2. The data reaches the router.
3. The router checks the **destination IP address**.
4. It checks its routing information.
5. It forwards the packet toward the appropriate network.

**Simple flow:**

**Laptop → Router → Internet → Server**
