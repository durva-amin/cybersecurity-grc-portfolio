## Definition

A **MAC Address (Media Access Control Address)** is a **unique hardware address assigned to a network interface** such as a Wi-Fi or Ethernet adapter.

**Simple Definition:**

> A MAC address is the **hardware-level address used to identify a network interface on a local network.**

---

## MAC Address Format

A typical MAC address is **48 bits (6 bytes)** and is usually written as six pairs of hexadecimal characters.

Example:

**`00:1A:2B:3C:4D:5E`**

Another common format is:

**`00-1A-2B-3C-4D-5E`**

---

## What is a MAC Address Used For?

It helps:

- Identify a network interface on a local network.
- Deliver Ethernet frames to the correct device.
- Switches determine where to forward frames.

---

## MAC Address vs IP Address

|MAC Address|IP Address|
|---|---|
|Hardware/link-layer address|Logical network-layer address|
|Used mainly on local networks|Used for communication across networks|
|Usually 48 bits for Ethernet/Wi-Fi|IPv4 = 32 bits, IPv6 = 128 bits|
|Written in hexadecimal|IPv4 written in decimal, IPv6 in hexadecimal|
|Example: `00:1A:2B:3C:4D:5E`|Example: `192.168.1.10`|
