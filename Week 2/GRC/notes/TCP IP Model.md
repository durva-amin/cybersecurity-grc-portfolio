## Definition

The **TCP/IP Model** is a networking model that explains **how data is transmitted between devices over a network or the Internet**.

**Simple Definition:**

> TCP/IP Model is a **4-layer model used to understand Internet communication.**

---

## The 4 Layers

|Layer|Name|Simple Meaning|
|---|---|---|
|4|**Application**|Network services used by applications|
|3|**Transport**|End-to-end data delivery|
|2|**Internet**|IP addressing and routing|
|1|**Network Access**|Physical network and data transmission|

### Easy Order

**Application → Transport → Internet → Network Access**

---

## 1. Application Layer

Provides network services directly to applications.

**Examples:**

- HTTP/HTTPS
- DNS
- FTP
- SMTP
- SSH

---

## 2. Transport Layer

Responsible for **communication between devices from end to end**.

Main protocols:

- **TCP** → Reliable delivery
- **UDP** → Faster delivery without guaranteed reliability

---

## 3. Internet Layer

Responsible for **IP addressing and routing packets** between networks.

**Main protocol:**

- IP

---

## 4. Network Access Layer

Responsible for **sending data over the actual network connection**.

Examples:

- Ethernet
- Wi-Fi
