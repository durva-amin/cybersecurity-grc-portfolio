## Definition

**DNS (Domain Name System)** is a system that **translates human-readable domain names into IP addresses** so computers can locate servers on a network.

**Simple Definition:**

> DNS is like the **phonebook of the Internet**. It converts a website name into its IP address.

---

## Why is DNS Needed?

Humans can easily remember:

**`google.com`**

But computers communicate using IP addresses such as:

**`142.250.x.x`**

DNS helps translate:

**Domain Name → IP Address**

---

## How Does DNS Work?

When you type `example.com` into your browser:

1. Your device asks a DNS server for the IP address.
2. The DNS server finds the IP address.
3. The IP address is returned to your device.
4. Your device uses that IP address to connect to the website.
