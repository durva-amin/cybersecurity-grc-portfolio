## Definition

A **Firewall** is a security system that **monitors and controls network traffic based on predefined security rules**.

**Simple Definition:**

> A Firewall acts like a **security gate** that allows or blocks network traffic according to rules.

---

## What Does a Firewall Do?

A firewall can:

- Allow legitimate network traffic.
- Block unauthorized traffic.
- Monitor network connections.
- Control access between networks.
- Help protect systems from network-based attacks.

---

## How Does a Firewall Work?

A firewall checks network traffic against its security rules.

For example:

**Allowed traffic → ✅ Permit**

**Blocked traffic → ❌ Deny**

Rules can consider things such as:

- Source IP address
- Destination IP address
- Port
- Protocol
- Connection information

---

## Types of Firewalls

Common types include:

### 1. Network Firewall

Protects a network by controlling traffic entering or leaving it.

### 2. Host-Based Firewall

Runs on an individual computer or server and controls its network traffic.

### 3. Next-Generation Firewall (NGFW)

Provides advanced inspection and security capabilities beyond basic filtering.
