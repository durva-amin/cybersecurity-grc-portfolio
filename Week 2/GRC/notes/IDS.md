## Definition

**IDS (Intrusion Detection System)** is a security system that **monitors network or system activity and detects suspicious or malicious activity.**

**Simple Definition:**

> IDS **detects and alerts** when it finds suspicious activity.

---

## What Does an IDS Do?

An IDS can:

- Monitor network traffic or system activity.
- Detect suspicious behavior.
- Identify possible attacks.
- Generate alerts for security teams.
- Help with security monitoring and investigation.

---

## How Does IDS Work?

1. IDS monitors network traffic or system activity.
2. It analyzes the activity using detection rules or patterns.
3. If suspicious activity is detected, it generates an **alert**.
4. A security team investigates and takes action.

**Simple flow:**

**Network Traffic → IDS → Detects Suspicious Activity → Alert 🚨**

---

## Types of IDS

### 1. NIDS

**Network Intrusion Detection System**

Monitors network traffic to detect suspicious activity.

### 2. HIDS

**Host Intrusion Detection System**

Monitors activity on an individual computer or server.
