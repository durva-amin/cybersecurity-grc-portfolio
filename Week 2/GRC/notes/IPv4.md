## Definition

**IPv4 (Internet Protocol version 4)** is the most widely used version of the Internet Protocol that uses **32-bit addresses** to identify devices on a network.

**Simple Definition:**

> IPv4 is a system that gives devices a **32-bit IP address** so they can communicate over a network.

---

## IPv4 Address Format

An IPv4 address has **32 bits**, divided into **4 parts called octets**.

Example:

**192.168.1.10**

Each octet:

- Contains **8 bits**
- Can have a value from **0 to 255**

So:

**192 | 168 | 1 | 10**

= **4 × 8 = 32 bits**

---

## Example

**192.168.1.10**

This is a valid IPv4 address.

Another example:

**8.8.8.8**

This is a public IPv4 address used by Google's public DNS service.

---

## Why is IPv4 Used?

IPv4 provides addresses that allow devices to:

- Be identified on a network.
- Communicate with other devices.
- Send and receive data.
- Allow routers to deliver packets to the correct destination.

---

## Main Limitation of IPv4

IPv4 has approximately **4.3 billion possible addresses**.

Because the number of Internet-connected devices has grown significantly, IPv4 addresses have become limited.

This is one of the major reasons **IPv6** was developed.
