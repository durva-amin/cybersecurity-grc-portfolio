## Definition

**HTTP (Hypertext Transfer Protocol)** is a protocol used for **communication between a web browser and a web server**.

**Simple Definition:**

> HTTP is the protocol used to **request and transfer web content** between a client and a server.

---

## What Does HTTP Do?

When you visit a website, HTTP helps your browser:

- Send requests to a web server.
- Receive web pages and other resources.
- Communicate with web applications.

---

## How HTTP Works

1. You enter a website address in your browser.
2. The browser sends an **HTTP request** to the server.
3. The server processes the request.
4. The server sends an **HTTP response**.
5. The browser displays the content.

**Simple flow:**

**Browser → HTTP Request → Web Server → HTTP Response → Browser**

---

## Example

You enter:

`http://example.com`

Your browser sends an HTTP request to the website's server.

The server responds with the requested webpage.

---

## HTTP Methods

Some common HTTP methods are:

- **GET** → Request data
- **POST** → Send data to the server
- **PUT** → Update data
- **DELETE** → Delete data

---
