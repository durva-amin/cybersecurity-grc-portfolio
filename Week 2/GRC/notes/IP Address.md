## Definition

An **IP Address (Internet Protocol Address)** is a **unique numerical address assigned to a device on a network so that it can be identified and communicate with other devices.**

**Simple Definition:**

> An IP address is like a **digital address of a device on a network**.

---

## Purpose of an IP Address

An IP address helps to:

- Identify a device on a network.
- Locate the device logically on the network.
- Send and receive data between devices.
- Help routers determine where data should go.

---

## Types of IP Addresses

There are two main versions:

- **IPv4** → Uses 32-bit addresses.
- **IPv6** → Uses 128-bit addresses.

You will study IPv4 and IPv6 separately, so remember only this basic distinction for now.

---

## Example

An IPv4 address can look like:

**192.168.1.10**

This address can identify a device on a network.
