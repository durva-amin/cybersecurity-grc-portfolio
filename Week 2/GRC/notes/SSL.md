## Definition

**SSL (Secure Sockets Layer)** is an older security protocol designed to **secure communication between two systems over a network by providing encryption and authentication**.

**Simple Definition:**

> SSL was used to **secure data while it travels between a client and server**.

---

## What Does SSL Provide?

SSL was designed to provide:

- **Encryption** → Protects data from being read by others.
- **Authentication** → Helps verify the identity of the server.
- **Integrity** → Helps detect if data was changed during transmission.

---

## Important Point

**SSL is now outdated and should not be used.**

Modern secure connections use **TLS (Transport Layer Security)**, which replaced SSL.

You may still hear people say **"SSL certificate"**, but modern websites generally use **TLS certificates/protocols**.

---

## SSL and HTTPS

HTTPS uses a security protocol to protect HTTP communication.

Historically:

**HTTP + SSL → HTTPS**

Today:

**HTTP + TLS → HTTPS**
