## Definition

**HTTPS (Hypertext Transfer Protocol Secure)** is the **secure version of HTTP** that protects communication between a browser and a web server using **TLS encryption**.

**Simple Definition:**

> HTTPS is HTTP with **secure, encrypted communication**.

---

## Why is HTTPS Used?

HTTPS helps protect data from:

- Being read by unauthorized people
- Being modified during transmission
- Being intercepted on the network

It is especially important when sending:

- Passwords
- Banking information
- Personal information
- Login credentials

---

## How HTTPS Works

1. You visit a website using `https://`.
2. The browser connects to the server.
3. **TLS** establishes a secure connection.
4. Data exchanged between the browser and server is encrypted.

**Simple flow:**

**Browser → Secure TLS Connection → Web Server**
