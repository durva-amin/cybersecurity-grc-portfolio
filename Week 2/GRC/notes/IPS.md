## Definition

**IPS (Intrusion Prevention System)** is a security system that **monitors network traffic, detects suspicious or malicious activity, and can automatically take action to block or prevent it.**

**Simple Definition:**

> IPS **detects and blocks** suspicious or malicious activity.

---

## What Does an IPS Do?

An IPS can:

- Monitor network traffic.
- Detect malicious activity.
- Block suspicious traffic.
- Prevent certain attacks from reaching systems.
- Generate alerts for security teams.

---

## How Does IPS Work?

1. IPS monitors network traffic.
2. It analyzes the traffic using security rules and detection methods.
3. It identifies suspicious or malicious activity.
4. It can **block, drop, or otherwise prevent the traffic**.
5. It can also generate an alert.

**Simple flow:**

**Network Traffic → IPS → Detects Threat → Blocks/Prevents 🚫**

---

## Types of IPS

### 1. Network-Based IPS (NIPS)

Monitors network traffic and can prevent malicious network activity.

### 2. Host-Based IPS (HIPS)

Runs on an individual system and monitors activity on that host.
