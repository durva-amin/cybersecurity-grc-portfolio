- **NAT = Network Address Translation**
- Translates IP addresses.
- Commonly converts **Private IP → Public IP** for Internet access.
- Helps conserve **IPv4 addresses**.
- **PAT** allows many private devices to share one public IP.
- NAT is **not the same as a firewall**.


### Easy Trick

**NAT = Private ↔ Public**

**Many private devices → One public IP → Internet**
