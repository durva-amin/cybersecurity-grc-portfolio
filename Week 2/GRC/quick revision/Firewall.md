- **Firewall = Controls network traffic**
- Uses **security rules**.
- Can allow or block traffic.
- Can filter based on IP addresses, ports, protocols, and connection information.
- Can be **hardware or software**.
- Does **not** stop every type of cyber attack.




### Easy Trick

**Firewall = Security Gate**

> **Allowed traffic → Enter ✅**  
> **Unauthorized traffic → Block ❌**
