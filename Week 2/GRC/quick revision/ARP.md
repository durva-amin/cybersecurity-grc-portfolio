- **ARP = Address Resolution Protocol**
- Used with **IPv4**
- Finds **MAC address from an IP address**
- Works on the **local network**
- Uses **ARP Request → ARP Reply**
- Stores learned information in an **ARP cache**


### Easy Trick

**ARP:**

**IP → MAC**

Think:

> **"I know the IP, but I need the MAC." → ARP**
