- **TCP/IP = 4-layer networking model**
- **Application** → Network services
- **Transport** → TCP/UDP and data delivery
- **Internet** → IP addressing and routing
- **Network Access** → Actual network transmission


You may be asked:

**"What is the difference between OSI and TCP/IP?"**

Remember the basic point:

- **OSI → 7 layers**
- **TCP/IP → 4 layers**
- OSI is mainly a **reference model for understanding networking**.
- TCP/IP is the **practical protocol suite/model used for Internet communication**.
