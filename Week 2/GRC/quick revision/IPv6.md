- **IPv6 = Internet Protocol version 6**
- **128-bit** address
- Written in **hexadecimal**
- Uses **8 groups**
- Groups are separated by **colons**
- Developed mainly to solve the **IPv4 address shortage**


### Easy Trick to Remember

**IPv4 → 32 bits → 4 decimal parts**

**IPv6 → 128 bits → 8 hexadecimal groups**

**IPv4:** `192.168.1.10`

**IPv6:** `2001:db8::1`
