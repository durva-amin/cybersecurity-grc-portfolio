- **DHCP = Dynamic Host Configuration Protocol**
- Automatically provides **IP configuration**.
- Can provide:
    - IP Address
    - Subnet Mask
    - Default Gateway
    - DNS Server
- Uses **DORA**:  
    **Discover → Offer → Request → Acknowledge**


### Easy Trick

**DHCP = Automatically gives network settings**

**DORA = How DHCP gives them**
