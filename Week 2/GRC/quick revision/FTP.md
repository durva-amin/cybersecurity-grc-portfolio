- **FTP = File Transfer Protocol**
- Used to **upload/download files**.
- Client ↔ Server
- **Port 21 → Control**
- **Port 20 → Traditionally data in active mode**
- Traditional FTP is **not encrypted**.
- **SFTP/FTPS → Secure alternatives**
