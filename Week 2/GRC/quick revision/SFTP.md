- **SFTP = SSH File Transfer Protocol**
- Secure file transfer.
- Runs over **SSH**.
- Common port: **22**
- Provides encrypted communication.
- **SFTP ≠ FTPS**
- **FTP → Not encrypted by default**
- **SFTP → Encrypted through SSH**
