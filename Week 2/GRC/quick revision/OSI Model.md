

# Quick Revision

- **OSI = 7-layer networking model**
- **L7:** Application → Network services
- **L6:** Presentation → Format/encryption
- **L5:** Session → Manages sessions
- **L4:** Transport → Data delivery
- **L3:** Network → IP/routing
- **L2:** Data Link → MAC/frames
- **L1:** Physical → Cables/signals

### Layer order:

**A P S T N D P**

> **All People Seem To Need Data Processing**

### Layer + key concept:

> **7 Application → Apps**  
> **6 Presentation → Format**  
> **5 Session → Session**  
> **4 Transport → TCP/Ports**  
> **3 Network → IP**  
> **2 Data Link → MAC**  
> **1 Physical → Cable**

### One-line memory:

> **Application → Presentation → Session → Transport → Network → Data Link → Physical**

If you remember **"IP = Layer 3, MAC = Layer 2, TCP/UDP = Layer 4, Applications = Layer 7"**, you already have the most important OSI associations for an entry-level cybersecurity interview.




### Interview Tip

For interviews, don't just memorize the seven names. Remember these **four important layers** especially well:

**Layer 7 → Application**  
**Layer 4 → Transport**  
**Layer 3 → Network**  
**Layer 2 → Data Link**

These are commonly used when explaining protocols, IP addresses, MAC addresses, TCP/UDP, and network troubleshooting.
