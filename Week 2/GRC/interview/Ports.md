# Interview Questions

### Q1. What is a port in networking?

**Answer:**  
A port is a logical communication endpoint used to identify a network service or application on a device.

### Q2. What is the range of TCP/UDP port numbers?

**Answer:**  
**0 to 65,535.**

### Q3. What is the difference between an IP address and a port?

**Answer:**  
An **IP address identifies the device**, while a **port identifies the network service or application endpoint**.

### Q4. Give examples of common ports.

**Answer:**  
**22 for SSH, 53 for DNS, 80 for HTTP, and 443 for HTTPS.**

### Q5. Can two applications use the same port?

**Answer:**  
Two applications generally cannot listen on the **same IP address and same protocol/port combination** at the same time. Different protocols, such as TCP and UDP, can use the same port number independently.

# Scenario-Based Question

### Q. A server has IP address `10.0.0.5` and is running an HTTPS service. How would you identify the HTTPS service on that server?

**Answer:**

**`10.0.0.5:443`**

`10.0.0.5` identifies the server, and **443** identifies the HTTPS service endpoint.
