# Interview Questions

### Q1. What is DHCP?

**Answer:**  
DHCP is a protocol that automatically assigns IP addresses and other network configuration settings to devices.

### Q2. What does DHCP stand for?

**Answer:**  
**Dynamic Host Configuration Protocol.**

### Q3. What is DORA in DHCP?

**Answer:**  
DORA is the four-step DHCP process:

**Discover → Offer → Request → Acknowledge**

### Q4. What information can DHCP provide?

**Answer:**  
IP address, subnet mask, default gateway, and DNS server information.

### Q5. What happens if DHCP is not available?

**Answer:**  
A device may not receive the correct network configuration automatically, so it may have difficulty communicating on the network.

# Scenario-Based Question

### Q. A new employee connects their laptop to the office network, and it automatically receives an IP address, subnet mask, gateway, and DNS server information. Which protocol is responsible?

**Answer:**  
**DHCP**, because it automatically provides the device with its network configuration.
