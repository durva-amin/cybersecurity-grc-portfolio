# Interview Questions

### Q1. What is the OSI Model?

**Answer:**  
The OSI Model is a 7-layer framework that explains how data is communicated between devices over a network.

### Q2. How many layers are in the OSI Model?

**Answer:**  
There are **7 layers**.

### Q3. Name all 7 layers.

**Answer:**  
Application, Presentation, Session, Transport, Network, Data Link, and Physical.

### Q4. Which layer is responsible for routing?

**Answer:**  
**Layer 3, Network Layer.**

### Q5. Which layer uses MAC addresses?

**Answer:**  
**Layer 2, Data Link Layer.**

### Q6. Which layer is responsible for reliable data delivery?

**Answer:**  
**Layer 4, Transport Layer.**

### Q7. Which is the top layer?

**Answer:**  
**Layer 7, Application Layer.**

### Q8. Which is the bottom layer?

**Answer:**  
**Layer 1, Physical Layer.**

# Scenario-Based Question

### Q. A network administrator finds that a cable is damaged and the device is not receiving any signal. Which OSI layer should they check?

**Answer:**  
**Layer 1, Physical Layer**, because it deals with cables, signals, connectors, and physical transmission.
