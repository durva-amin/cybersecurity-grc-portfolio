# Interview Questions

### Q1. What is IMAP?

**Answer:**  
IMAP is an email protocol used to access and manage emails stored on a mail server and synchronize them across devices.

### Q2. What does IMAP stand for?

**Answer:**  
**Internet Message Access Protocol.**

### Q3. Which ports does IMAP use?

**Answer:**  
**Port 143** for standard IMAP and **port 993** for IMAP over TLS.

### Q4. Is IMAP used for sending emails?

**Answer:**  
No. **SMTP** is mainly used for sending emails. IMAP is used for accessing and managing received emails.

### Q5. Why is IMAP useful for multiple devices?

**Answer:**  
Because emails and changes are stored/synchronized with the mail server, allowing multiple devices to access the same mailbox consistently.

# Scenario-Based Question

### Q. An employee checks the same email account on their phone and laptop and wants emails and read/unread status to stay synchronized. Which protocol is suitable?

**Answer:**  
**IMAP**, because it keeps the mailbox synchronized with the server across devices.
