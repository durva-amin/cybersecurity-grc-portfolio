# Interview Questions

### Q1. What is a MAC Address?

**Answer:**  
A MAC address is a hardware/link-layer address used to identify a network interface on a local network.

### Q2. What does MAC stand for?

**Answer:**  
**Media Access Control.**

### Q3. How long is a typical MAC address?

**Answer:**  
A typical Ethernet/Wi-Fi MAC address is **48 bits or 6 bytes**.

### Q4. Give an example of a MAC address.

**Answer:**  
`00:1A:2B:3C:4D:5E`

### Q5. What is the difference between a MAC Address and an IP Address?

**Answer:**  
A **MAC address** identifies a network interface at the local network/link layer, while an **IP address** is a logical address used for communication and routing between networks.

# Scenario-Based Question

### Q. A switch needs to forward a network frame to the correct device on the same LAN. Which address does it primarily use?

**Answer:**  
The **MAC address**, because switches use MAC addresses to forward Ethernet frames within a local network.
