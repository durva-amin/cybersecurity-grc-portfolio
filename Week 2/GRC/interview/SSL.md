# Interview Questions

### Q1. What is SSL?

**Answer:**  
SSL is an older security protocol designed to provide encryption, authentication, and integrity for communication over a network.

### Q2. What does SSL stand for?

**Answer:**  
**Secure Sockets Layer.**

### Q3. Is SSL still used today?

**Answer:**  
No. SSL is outdated and has been replaced by **TLS**.

### Q4. What is the relationship between SSL and HTTPS?

**Answer:**  
HTTPS is HTTP secured using a cryptographic security protocol. Historically, SSL was used, but modern HTTPS uses **TLS**.

### Q5. What replaced SSL?

**Answer:**  
**TLS (Transport Layer Security)** replaced SSL.

---

# Scenario-Based Question

### Q. An interviewer says, "This website uses SSL to protect HTTPS traffic." What should you clarify?

**Answer:**  
Modern HTTPS uses **TLS**, not the old SSL protocols. People may still use the term "SSL" informally when referring to HTTPS/TLS security.
