# Interview Questions

### Q1. What is an IP Address?

**Answer:**  
An IP address is a logical address assigned to a device on a network so that the device can be identified and communicate with other devices.

---

### Q2. Why do we need an IP Address?

**Answer:**  
We need IP addresses to identify devices and help route data between them.

---

### Q3. Is an IP address a physical address?

**Answer:**  
No. An IP address is a **logical address**. A MAC address is associated with the network interface at the data-link level.

---

### Q4. What are the two main versions of IP?

**Answer:**  
**IPv4 and IPv6.**

---

### Q5. Can two devices have the same IP address?

**Answer:**  
Two devices should not have the same IP address **within the same network where that address must be unique**, because it can cause an IP address conflict.

---

# Scenario-Based Question

### Q. Your laptop wants to send data to another computer on a network. How does the network know which device the data is intended for?

**Answer:**  
The **IP address** helps identify the destination device and allows the network to route the data toward it.
