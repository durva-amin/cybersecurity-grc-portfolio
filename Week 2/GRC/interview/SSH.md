# Interview Questions

### Q1. What is SSH?

**Answer:**  
SSH is a secure network protocol used for remote login and administration of computers and servers.

### Q2. What does SSH stand for?

**Answer:**  
**Secure Shell.**

### Q3. Which port does SSH commonly use?

**Answer:**  
**Port 22.**

### Q4. Why is SSH considered secure?

**Answer:**  
SSH uses cryptographic protection to secure the connection and help protect authentication and data exchanged between the client and server.

### Q5. What is SSH commonly used for?

**Answer:**  
It is commonly used for **secure remote login, server administration, and executing commands on remote systems**.

### Q6. Is SSH the same as Telnet?

**Answer:**  
No. SSH provides secure, encrypted communication, while traditional Telnet sends communication without encryption.

# Scenario-Based Question

### Q. A system administrator needs to remotely log in to a Linux server and execute commands securely. Which protocol should they use?

**Answer:**  
**SSH**, because it provides secure remote access and command execution.
