# Interview Questions

### Q1. What is a Hub?

**Answer:**  
A hub is a basic networking device that connects devices in a LAN and broadcasts incoming data to all connected ports.

### Q2. Which OSI layer does a Hub operate at?

**Answer:**  
**Layer 1, Physical Layer.**

### Q3. Does a Hub use MAC addresses?

**Answer:**  
No. A basic hub does not use MAC addresses to decide where to forward traffic.

### Q4. Why is a Hub less efficient than a Switch?

**Answer:**  
Because a hub sends incoming traffic to all connected devices, creating unnecessary traffic and more collisions.

### Q5. Are Hubs commonly used in modern networks?

**Answer:**  
No. **Switches are generally preferred** because they can forward traffic more efficiently to the intended destination.

# Scenario-Based Question

### Q. A device sends data to one computer, but the network device broadcasts that data to every connected computer. Which device is likely being used?

**Answer:**  
A **Hub**, because it broadcasts incoming traffic to all connected ports.
