# Interview Questions

### Q1. What is the TCP/IP Model?

**Answer:**  
The TCP/IP Model is a 4-layer networking model that explains how data is transmitted between devices over a network.

---

### Q2. How many layers are in the TCP/IP Model?

**Answer:**  
The commonly used TCP/IP model has **4 layers**.

---

### Q3. Name the four layers.

**Answer:**

1. Application
2. Transport
3. Internet
4. Network Access

---

### Q4. Which layer is responsible for IP addressing and routing?

**Answer:**  
**Internet Layer.**

---

### Q5. Which layer uses TCP and UDP?

**Answer:**  
**Transport Layer.**

---

### Q6. Give examples of Application Layer protocols.

**Answer:**  
HTTP, HTTPS, DNS, FTP, SMTP, and SSH.

---

# Scenario-Based Question

### Q. A packet needs to travel from one network to another, and the system needs to determine the appropriate route. Which TCP/IP layer handles this?

**Answer:**  
**Internet Layer**, because it handles IP addressing and routing.
