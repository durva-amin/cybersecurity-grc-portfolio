# Interview Questions

### Q1. What is a Router?

**Answer:**  
A router is a networking device that connects different networks and forwards packets between them using IP addresses.

### Q2. What is the main function of a Router?

**Answer:**  
Its main function is to **forward packets between networks based on destination IP addresses**.

### Q3. Which address does a Router primarily use for routing?

**Answer:**  
The **IP address**.

### Q4. Can a Router connect a local network to the Internet?

**Answer:**  
Yes. A router can connect a local network to an external network such as the Internet.

### Q5. What is the relationship between a Router and Default Gateway?

**Answer:**  
A router commonly acts as the **default gateway**, allowing devices on a local network to communicate with other networks.

# Scenario-Based Question

### Q. Computers in an office can communicate with each other, but they need to communicate with a server located on another network. Which device can forward their traffic to that network?

**Answer:**  
A **Router**, because it connects different networks and forwards packets between them.
