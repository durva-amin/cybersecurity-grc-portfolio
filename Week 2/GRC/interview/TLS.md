# Interview Questions

### Q1. What is TLS?

**Answer:**  
TLS is a security protocol that protects network communication using encryption, authentication, and integrity.

### Q2. What does TLS stand for?

**Answer:**  
**Transport Layer Security.**

### Q3. What replaced SSL?

**Answer:**  
**TLS replaced SSL.**

### Q4. What are the main security benefits of TLS?

**Answer:**  
**Confidentiality through encryption, authentication, and data integrity.**

### Q5. Does HTTPS use TLS?

**Answer:**  
Yes. Modern HTTPS uses **TLS** to secure HTTP communication.

# Scenario-Based Question

### Q. A user logs into a website using HTTPS. An attacker is monitoring the network. What technology helps protect the user's login information from being read in transit?

**Answer:**  
**TLS**, because it encrypts the communication between the browser and the web server.
