# Interview Questions

### Q1. What is HTTP?

**Answer:**  
HTTP is a protocol used for communication between web clients and web servers to request and transfer web resources.

### Q2. What does HTTP stand for?

**Answer:**  
**Hypertext Transfer Protocol.**

### Q3. Which port does HTTP commonly use?

**Answer:**  
**Port 80.**

### Q4. What is an HTTP Request?

**Answer:**  
An HTTP Request is a message sent by a client, such as a browser, to a web server asking for a resource or requesting an action.

### Q5. What is an HTTP Response?

**Answer:**  
An HTTP Response is the message sent by the server back to the client after processing the request.

### Q6. Is HTTP encrypted?

**Answer:**  
No. HTTP itself does not encrypt the communication.

# Scenario-Based Question

### Q. A user visits a website using `http://` instead of `https://`. What security concern exists?

**Answer:**  
HTTP does not encrypt the communication, so sensitive information transmitted through the connection could potentially be intercepted or modified.
