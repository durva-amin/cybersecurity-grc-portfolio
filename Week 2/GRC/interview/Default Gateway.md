# Interview Questions

### Q1. What is a Default Gateway?

**Answer:**  
A Default Gateway is usually a router that forwards traffic from a local network to other networks.

### Q2. Why do we need a Default Gateway?

**Answer:**  
We need it to communicate with devices outside our local network, including accessing the Internet.

### Q3. What is a common example of a Default Gateway?

**Answer:**  
In a home network, it could be something like **`192.168.1.1`**, although the actual address depends on the network configuration.

### Q4. What happens if the Default Gateway is unavailable?

**Answer:**  
Devices can usually still communicate with devices on their local network, but they may not be able to communicate with other networks or access the Internet.

# Scenario-Based Question

### Q. Your laptop can communicate with other computers connected to the same Wi-Fi, but it cannot access any website on the Internet. The IP configuration shows that the Default Gateway is missing. What could be the problem?

**Answer:**  
The missing Default Gateway can prevent the laptop from sending traffic outside its local network.
