# Interview Questions

### Q1. What is HTTPS?

**Answer:**  
HTTPS is the secure version of HTTP that uses TLS to protect communication between a browser and a web server.

### Q2. What does HTTPS stand for?

**Answer:**  
**Hypertext Transfer Protocol Secure.**

### Q3. Which port does HTTPS commonly use?

**Answer:**  
**Port 443.**

### Q4. Is HTTPS encrypted?

**Answer:**  
Yes. HTTPS uses **TLS** to encrypt the communication between the client and server.

### Q5. Why is HTTPS important?

**Answer:**  
It helps protect data from being intercepted or modified while it is transmitted between the browser and server.

# Scenario-Based Question

### Q. A user enters their username and password on a website. The browser shows a secure HTTPS connection. What security benefit does HTTPS provide?

**Answer:**  
HTTPS uses TLS to encrypt the communication, helping protect the credentials while they travel between the browser and the server.
