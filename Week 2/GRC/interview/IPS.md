# Interview Questions

### Q1. What is an IPS?

**Answer:**  
An IPS is a security system that monitors network or system activity, detects suspicious activity, and can automatically take action to prevent it.

### Q2. What does IPS stand for?

**Answer:**  
**Intrusion Prevention System.**

### Q3. What is the main difference between IDS and IPS?

**Answer:**  
**IDS detects and alerts**, while **IPS detects and can automatically block or prevent** malicious activity.

### Q4. Can an IPS generate alerts?

**Answer:**  
Yes. An IPS can generate alerts in addition to taking preventive action.

### Q5. What are common types of IPS?

**Answer:**

- **NIPS** → Network-based IPS
- **HIPS** → Host-based IPS

# Scenario-Based Question

### Q. A security system detects malicious traffic and automatically blocks it before it reaches the company's server. What security system is being used?

**Answer:**  
**IPS**, because it can detect malicious activity and automatically take preventive action.
