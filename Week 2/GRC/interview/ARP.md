# Interview Questions

### Q1. What is ARP?

**Answer:**  
ARP is a protocol used in IPv4 networks to find the MAC address associated with a known IP address on the local network.

### Q2. What does ARP stand for?

**Answer:**  
**Address Resolution Protocol.**

### Q3. What does ARP resolve?

**Answer:**  
It resolves an **IPv4 address to a MAC address**.

### Q4. What is an ARP Request?

**Answer:**  
An ARP Request is a message asking which device owns a particular IP address and requesting its MAC address.

### Q5. What is an ARP Reply?

**Answer:**  
An ARP Reply provides the MAC address associated with the requested IPv4 address.

### Q6. Where is the ARP information stored?

**Answer:**  
It is commonly stored in the device's **ARP cache/table** for a period of time.

# Scenario-Based Question

### Q. A computer knows that the server's IP address is `192.168.1.50`, but it does not know the server's MAC address. Which protocol can help?

**Answer:**  
**ARP**, because it can resolve the known IPv4 address to the corresponding MAC address on the local network.
