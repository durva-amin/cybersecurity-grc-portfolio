# Interview Questions

### Q1. What is IPv6?

**Answer:**  
IPv6 is Internet Protocol version 6, which uses **128-bit addresses** to identify devices and communicate over networks.

---

### Q2. How many bits are in an IPv6 address?

**Answer:**  
**128 bits.**

---

### Q3. How is an IPv6 address written?

**Answer:**  
It is written using **8 groups of hexadecimal numbers separated by colons**.

Example:

`2001:db8:85a3::8a2e:370:7334`

---

### Q4. Why was IPv6 introduced?

**Answer:**  
Mainly because IPv4 has a limited number of available addresses, while IPv6 provides a much larger address space.

---

### Q5. What is the main difference between IPv4 and IPv6?

**Answer:**

- **IPv4:** 32-bit address
- **IPv6:** 128-bit address

---

# Scenario-Based Question

### Q. A company has a very large number of Internet-connected devices and needs a much larger pool of IP addresses. Which IP version would be more suitable?

**Answer:**  
**IPv6**, because it provides a much larger address space than IPv4.
