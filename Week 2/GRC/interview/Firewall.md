# Interview Questions

### Q1. What is a Firewall?

**Answer:**  
A firewall is a security system that monitors and controls network traffic based on predefined security rules.

### Q2. What is the main purpose of a Firewall?

**Answer:**  
To control network traffic and prevent unauthorized access to systems or networks.

### Q3. Can a Firewall block specific ports?

**Answer:**  
Yes. Firewall rules can allow or block traffic based on **port numbers**, along with other factors.

### Q4. Is a Firewall hardware or software?

**Answer:**  
A firewall can be **hardware, software, or a combination of both**.

### Q5. Does a Firewall stop all cyber attacks?

**Answer:**  
No. A firewall is an important security control, but it cannot protect against every type of attack. Other security controls are also required.

# Scenario-Based Question

### Q. An organization wants to prevent unauthorized incoming connections to its internal network while allowing approved traffic. Which security control can be used?

**Answer:**  
A **Firewall**, because it can monitor incoming traffic and allow or block connections according to security rules.
