# Interview Questions

### Q1. What is IPv4?

**Answer:**  
IPv4 is Internet Protocol version 4, which uses **32-bit addresses** to identify devices and enable communication over networks.

---

### Q2. How many bits are in an IPv4 address?

**Answer:**  
**32 bits.**

---

### Q3. How many octets are in an IPv4 address?

**Answer:**  
**4 octets.**

---

### Q4. What is the range of each IPv4 octet?

**Answer:**  
**0 to 255.**

---

### Q5. Give an example of an IPv4 address.

**Answer:**  
**192.168.1.10**

---

### Q6. Why was IPv6 introduced?

**Answer:**  
IPv6 was introduced mainly because the number of available IPv4 addresses is limited.

---

# Scenario-Based Question

### Q. A network administrator sees an address written as `192.168.10.25`. What type of IP address format is this?

**Answer:**  
It is an **IPv4 address**, because it contains four decimal octets separated by dots.
