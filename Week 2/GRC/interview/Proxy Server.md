# Interview Questions

### Q1. What is a Proxy Server?

**Answer:**  
A proxy server is an intermediary that receives requests from a client and forwards them to a destination server.

### Q2. Why is a Proxy Server used?

**Answer:**  
It can be used for **traffic filtering, access control, logging, caching, and acting as an intermediary between clients and destination servers**.

### Q3. Does a Proxy Server encrypt traffic?

**Answer:**  
Not necessarily. **Encryption depends on the proxy and the protocol being used.** A proxy itself does not automatically mean that all traffic is encrypted.

### Q4. Can a Proxy Server hide a user's IP address from a website?

**Answer:**  
Yes, typically the website sees the proxy's IP address instead of the client's original IP address.

### Q5. What is the difference between a Proxy and a VPN?

**Answer:**  
A proxy generally acts as an intermediary for specific traffic or applications, while a VPN creates a secure connection that can route broader device traffic through the VPN server.

# Scenario-Based Question

### Q. A company wants to block employees from accessing certain websites and keep logs of their web requests. What could it use?

**Answer:**  
A **Proxy Server**, configured with appropriate filtering and logging rules.
