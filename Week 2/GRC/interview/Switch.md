# Interview Questions

### Q1. What is a Switch?

**Answer:**  
A switch is a networking device that connects devices within a LAN and forwards Ethernet frames using MAC addresses.

### Q2. Which address does a Switch primarily use?

**Answer:**  
A **MAC address**.

### Q3. What is a MAC Address Table?

**Answer:**  
It is a table maintained by a switch that maps **MAC addresses to switch ports**, helping the switch know where to forward frames.

### Q4. Which OSI layer does a traditional Switch operate at?

**Answer:**  
Primarily **Layer 2, the Data Link Layer**.

Some advanced Layer 3 switches can also perform routing functions.

### Q5. What is the difference between a Switch and a Router?

**Answer:**

- **Switch:** Connects devices within a LAN and primarily uses MAC addresses.
- **Router:** Connects different networks and uses IP addresses for routing.

# Scenario-Based Question

### Q. An office has 15 computers that need to communicate with each other on the same LAN. Which device would you use to connect them?

**Answer:**  
A **Switch**, because it connects multiple devices within a local network and forwards traffic using MAC addresses.
