# Interview Questions

### Q1. What is POP3?

**Answer:**  
POP3 is an email protocol used to retrieve emails from a mail server to an email client.

### Q2. What does POP3 stand for?

**Answer:**  
**Post Office Protocol version 3.**

### Q3. Which port does POP3 commonly use?

**Answer:**  
**Port 110** for standard POP3 and **port 995** for POP3 over TLS.

### Q4. Is POP3 used for sending emails?

**Answer:**  
No. **SMTP** is mainly used for sending emails. POP3 is used for retrieving emails.

### Q5. What is the difference between POP3 and IMAP?

**Answer:**  
POP3 mainly downloads emails to a device, while IMAP keeps emails on the server and synchronizes them across devices.

# Scenario-Based Question

### Q. An employee wants their emails to be downloaded from the mail server to their computer for local access. Which protocol could be used?

**Answer:**  
**POP3**, because it is designed for retrieving emails from a mail server.
