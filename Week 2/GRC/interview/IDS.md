# Interview Questions

### Q1. What is an IDS?

**Answer:**  
An IDS is a security system that monitors network or system activity and detects suspicious or malicious activity.

### Q2. What does IDS stand for?

**Answer:**  
**Intrusion Detection System.**

### Q3. What happens when an IDS detects suspicious activity?

**Answer:**  
It typically **generates an alert** for the security team to investigate.

### Q4. What are the two common types of IDS?

**Answer:**

- **NIDS** → Monitors network traffic.
- **HIDS** → Monitors activity on a specific host or system.

### Q5. Does an IDS automatically block an attack?

**Answer:**  
Normally, an IDS is primarily designed to **detect and alert**. An **IPS** is designed to take preventive action such as blocking malicious traffic.

# Scenario-Based Question

### Q. A security tool detects suspicious network traffic and immediately sends an alert to the security team but does not block the traffic. What is it?

**Answer:**  
An **IDS (Intrusion Detection System)**.
