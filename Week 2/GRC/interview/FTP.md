# Interview Questions

### Q1. What is FTP?

**Answer:**  
FTP is a network protocol used to transfer files between a client and a server.

### Q2. What does FTP stand for?

**Answer:**  
**File Transfer Protocol.**

### Q3. Which ports are commonly associated with FTP?

**Answer:**  
**Port 21** is used for the control connection. **Port 20** is traditionally used for the data connection in active FTP.

### Q4. Is FTP secure?

**Answer:**  
Traditional FTP is **not secure by default** because it does not encrypt the communication.

### Q5. What can be used instead of FTP for secure file transfer?

**Answer:**  
**SFTP** or **FTPS** can be used for secure file transfer.

---

# Scenario-Based Question

### Q. An administrator wants to transfer files between a computer and a server, but the files contain sensitive information. Would traditional FTP be a good choice?

**Answer:**  
No. Traditional FTP does not provide encryption. A secure alternative such as **SFTP** would be more appropriate.
