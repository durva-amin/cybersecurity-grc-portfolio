# Interview Questions

### Q1. What is DNS?

**Answer:**  
DNS is a system that translates domain names into IP addresses so devices can locate servers on a network.

### Q2. What does DNS stand for?

**Answer:**  
**Domain Name System.**

### Q3. Why is DNS important?

**Answer:**  
It allows users to access websites using easy-to-remember domain names instead of numerical IP addresses.

### Q4. What happens if DNS is not working?

**Answer:**  
You may be unable to access websites using their domain names, even though your device may still have network connectivity.

### Q5. Is DNS only used for websites?

**Answer:**  
No. DNS is also used for other services, such as **email routing** and service discovery.

# Scenario-Based Question

### Q. Your computer is connected to the Internet, but you cannot open a website using its domain name. However, you can reach the server when using its IP address. What could be the problem?

**Answer:**  
There may be a **DNS resolution problem**, because the device cannot translate the domain name into an IP address.
