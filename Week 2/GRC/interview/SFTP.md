# Interview Questions

### Q1. What is SFTP?

**Answer:**  
SFTP is a secure file transfer protocol that transfers and manages files over an encrypted SSH connection.

### Q2. What does SFTP stand for?

**Answer:**  
**SSH File Transfer Protocol.**

### Q3. Which port does SFTP commonly use?

**Answer:**  
**Port 22.**

### Q4. Is SFTP encrypted?

**Answer:**  
Yes. SFTP operates over SSH, which provides encrypted communication.

### Q5. What is the difference between FTP and SFTP?

**Answer:**  
FTP does not encrypt communication by default, while SFTP transfers files through an encrypted SSH connection.

### Q6. Is SFTP the same as FTPS?

**Answer:**  
No.

**SFTP → SSH-based**

**FTPS → FTP secured with TLS**

# Scenario-Based Question

### Q. A company wants to securely transfer confidential files to a remote server. Which protocol would be more appropriate: FTP or SFTP?

**Answer:**  
**SFTP**, because it uses an encrypted SSH connection to protect the file transfer and authentication information.
